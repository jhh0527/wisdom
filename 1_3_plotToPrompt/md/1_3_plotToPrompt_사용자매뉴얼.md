# 1_3_plotToPrompt 사용자매뉴얼

줄거리(~700자)로 장별 **BRIEF**를 만들고, 젠스파크에 붙여넣을 **합본 프롬프트**를 만든 뒤, 완성 대본을 **`tts/{장}.txt`** 로 저장하는 GUI입니다.

현재 버전: **1.2.2**

---

## 1. 실행

| 방법 | 경로 |
|------|------|
| 권장 | `1_3_plotToPrompt/dist/1_3_plotToPrompt_gui.exe` |
| 소스 | `1_3_plotToPrompt/run_plot_to_prompt_gui.py` (개발용) |

창 제목: `1_3_plotToPrompt 1.2.2`

---

## 2. 화면 구성

위에서 아래로:

1. **경로** — 작품 폴더 · 작업 루트 · 장(경로에서 자동 표시)
2. **탭**
   - `1. 줄거리 → BRIEF`
   - `2. BRIEF → 합본 · tts 저장`
3. **상태 문구** · **진척 바** · **로그**

설정의 작품/작업 경로·바이블 동기화 여부는  
`dist/plot_to_prompt_gui_config.json`(exe 옆)에 저장됩니다.  
로그 파일: `dist/logs/plot_to_prompt.log`

---

## 3. 경로 설정

### 작품 폴더

소설 바이블이 있는 폴더입니다. 보통 `workspace/{작품slug}/`  
다음이 있으면 정상입니다.

- `chapter_map.md`
- `briefs/` (BRIEF 저장)
- (권장) `WRITE_RULES.md`, `characters.md`, `events.md`

### 작업 루트

장 작업 폴더, 또는 그 안의 `tts` 상위입니다.

| 예 | 의미 |
|----|------|
| `…/2부/14장` | 작업 루트 = 14장 폴더 → **14장** |
| `…/14장` | 동일 |
| `…/14장/tts`의 상위 | `…/14장` 을 작업 루트로 지정 |

- 장 번호는 **입력 칸이 없습니다.** 작업 루트 경로의 `N장`에서만 읽습니다.
- 작업 루트에서 위로 올라가 `chapter_map.md` 또는 `briefs/`가 보이면 **작품 폴더도 자동 추정**합니다.
- 경로에 `N장`이 없으면 BRIEF·합본·tts 저장이 되지 않습니다. `…/14장` 형태를 고르세요.

**「장」** 표시 옆 **「메타: …」** 는 `chapter_map` 등에서 읽은 본문 제목·사건 ID 요약입니다.

---

## 4. 탭 1 — 줄거리 → BRIEF

### 하는 일

1. 줄거리 입력(~700자 권장)
2. `chapter_map` / 타임라인 메타로 제목·나이·계절·사건 ID를 붙임
3. 줄거리를 비트(8~12개)로 나눠 BRIEF 마크다운 생성
4. `briefs/CHAPTER_{장}.md` 에 저장 (예: 14장 → `CHAPTER_14.md`)

### 조작

| 항목 | 설명 |
|------|------|
| 줄거리 (~700자) | 이 장에서 일어날 일. 글자 수는 오른쪽 표시 |
| BRIEF 미리보기 | 생성 결과. 저장 전·후 수정 가능 |
| **줄거리 반영 (chapter_map · events · 부줄거리)** | 켜면 BRIEF 저장 시 바이블도 같이 갱신 |
| **BRIEF 생성·저장** | 줄거리 → BRIEF 생성 → 미리보기 채움 → 파일 저장 (+ 체크 시 동기화) |
| **미리보기 다시 저장** | 미리보기 칸을 고친 뒤 파일만 다시 씀 (+ 체크 시 동기화) |

### 체크박스 「줄거리 반영」

켜져 있으면 저장할 때 작품 폴더의 다음을 맞춥니다.

- `chapter_map.md` — 해당 장 행
- `events.md` — 사건 요약
- `N부` 줄거리 파일 — `## 제N장` 구간

끌면 BRIEF 파일만 저장합니다.

### 산출물

```
{작품폴더}/briefs/CHAPTER_01.md   (장 1~9는 0채움, 10+도 두 자리 이상)
```

미리보기에서 비트·금지·훅 등을 손본 뒤 **미리보기 다시 저장**하면 됩니다.

### 정합성 검증 (권장)

장 줄거리를 넣어 BRIEF·바이블을 맞춘 뒤, 합본·본문 **전에** Cursor에서 정합성을 확인합니다.

```
@wuxia-check-plot 마지막 장 정합성 체크
```

또는 `N장 체크`. 부 줄거리를 Cursor로 넣은 경우에도 동일합니다.  
상세: `.cursor/skills/wuxia-check-plot/대본정합성체크_사용자매뉴얼.md` · 부·장 반영: `.cursor/skills/wuxia-add-plot/부장줄거리반영_사용자매뉴얼.md`

## 5. 탭 2 — BRIEF → 합본 · tts 저장

장 본문을 **젠스파크(또는 다른 LLM)** 로 쓸 때 쓰는 탭입니다.

### 권장 흐름

1. 탭1에서 해당 장 BRIEF를 저장해 둔다.
2. **합본 만들기** → WRITE_RULES + BRIEF + characters 발췌 + 직전 장 꼬리 + 작성 지시가 한 덩어리로 모임.
3. **합본 복사** → 젠스파크에 붙여넣기.
4. 모델이 `<<<CHAPTER_START>>>` … `<<<CHAPTER_END>>>` 로 감싼 본문을 출력하면 복사.
5. **클립보드 감시**가 켜져 있으면(기본 ON) 약 1.5초마다 감시해 START/END가 보이면 자동으로 `tts/{장}.txt` 저장.
6. 감시가 꺼져 있으면 **START/END로 저장**을 누른다.

### 버튼

| 버튼 | 설명 |
|------|------|
| **합본 만들기** | 디스크의 BRIEF 등으로 합본 생성 → 위 칸에 표시 |
| **합본 복사** | 합본을 클립보드에 복사 (비어 있으면 먼저 만들기) |
| **START/END로 저장** | 클립보드에서 구분자 사이 본문만 뽑아 `tts/{장}.txt` 저장 |
| **tts에서 불러오기** | 이미 있는 `tts/{장}.txt` 를 아래 칸에 표시 |
| **칸 내용 저장** | 아래 「추출된 본문」칸을 그대로(또는 START/END 추출 후) tts에 저장 |

### 클립보드 감시(START/END)

- 단독 exe 실행 시에만 동작합니다(허브 탭 임베드 시에는 폴링 안 함).
- 같은 내용을 반복 저장하지 않도록 해시로 한 번만 저장합니다.
- 작업 루트가 비어 있으면 저장하지 않습니다.

### 합본에 들어가는 것

| 블록 | 출처 |
|------|------|
| WRITE_RULES | `{작품}/WRITE_RULES.md` (없으면 내장 규칙) |
| BRIEF | `{작품}/briefs/CHAPTER_{장}.md` |
| characters | `{작품}/characters.md` (길면 앞 4000자) |
| 직전 장 꼬리 | `{작업루트}/tts/{장-1}.txt` 끝부분(~1200자) |
| 작성 지시 | 분량·START/END 필수 안내 |

### tts 저장 위치

```
{작업루트}/tts/{장번호}.txt
```

예: 작업 루트 `…/2부/14장`, 장 14 → `…/2부/14장/tts/14.txt`

구분자가 있으면 **사이 본문만** 저장합니다.  
「칸 내용 저장」은 구분자가 없으면 칸 전체 텍스트를 저장합니다.

필수 구분자:

```
<<<CHAPTER_START>>>
(제목 한 줄)
(본문)
<<<CHAPTER_END>>>
```

## 6. 한눈에 보는 파이프라인

```
장 줄거리(~700자) 또는 부 줄거리(Cursor @wuxia-add-plot)
    → [탭1] BRIEF 생성·저장  (+선택: chapter_map / events / 부줄거리)
    → Cursor @wuxia-check-plot (정합성 검증)   ← 본문 전 권장
    → [탭2] 합본 만들기 · 복사
    → 젠스파크 작성
    → START/END 결과 복사
    → tts/{장}.txt
    → (이후) 1_5_textToJson · 2_2_scriptToVoice 등
```

## 7. 자주 하는 질문

**Q. 장 번호는 어디에 넣나요?**  
넣지 않습니다. 작업 루트를 `…/14장`처럼 고르면 됩니다.

**Q. 「BRIEF 없음」이 뜹니다.**  
탭1에서 먼저 **BRIEF 생성·저장**을 하세요. 파일명 `CHAPTER_14.md` 등을 `briefs/`에서 찾습니다.

**Q. 합본 notes에 「직전 tts 없음」이 나옵니다.**  
1장이거나 이전 장 파일이 없을 때입니다. 합본은 만들어지며, 꼬리만 빠집니다.

**Q. 감시가 저장을 안 합니다.**  
START/END가 둘 다 있는지, 작업 루트에 `N장`이 있는지, 단독 exe인지 확인하세요. 안 되면 **START/END로 저장**을 쓰세요.

**Q. 바이블을 건드리지 않고 BRIEF만 만들고 싶습니다.**  
「줄거리 반영」 체크를 끄면 됩니다.

**Q. 줄거리는 꼭 700자인가요?**  
가이드 분량입니다. 비어 있으면 생성할 수 없고, 너무 짧으면 비트가 빈약해질 수 있습니다.

**Q. 줄거리 넣은 뒤 정합성은 어디서 보나요?**  
이 GUI에는 없습니다. Cursor에서 `@wuxia-check-plot` (장·부 줄거리 입력 후 권장).  
부 줄거리 반영은 `@wuxia-add-plot` → 이어서 같은 체크.

---

## 8. 주의사항

- BRIEF·바이블 동기화는 **선택한 작품 폴더의 파일을 직접 수정**합니다. 중요한 장은 백업을 권장합니다.
- 젠스파크 출력에 START/END가 없으면 자동 저장되지 않습니다. 프롬프트의 「필수」 지시를 지키게 하세요.
- 목표 본문 분량(합본 지시)은 약 **9,000~11,000자**입니다.
- MP3·음성 합성은 이 프로그램 범위가 아닙니다. `tts/*.txt` 이후 단계는 다른 모듈을 사용합니다.
)
