# 2_2_scriptToVoice

GUI: `dist/2_2_scriptToVoice_gui.exe` / `run_script_voice_gui.py`

- 대본에 `[1]` `[2]` … 단락 마커
- **변환** → `루트/mp3/01.mp3`, `02.mp3`, … (중간 파트 유지) + `lines.json`
- **병합** → 단락 사이 텀(기본 1초 무음) 후 `루트/mp3/all.mp3`
- MP3 생성 완료 시 **자동 병합** → `all.mp3`
- 파트 ``NN.txt`` 사이드카는 생성하지 않음(기존 잔여분은 완료 시 삭제). 매칭은 `lines.json`
- **변환** 시 진행률(%) 표시
- Voice/API: `2_1_ttsToVoice/dist/elsub_config*.json` 우선
