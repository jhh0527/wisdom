# {TITLE} — 작품 규칙 (CURSOR_RULES)

유튜브 무협 소설 제작용. AI는 새 장 작성·수정 시 이 규칙을 따른다.

## 필수 참조 파일

1. `events.md`
2. `chapter_map.md`
3. `world.md`
4. `characters.md`
5. `martial_arts.md`
6. `timeline.md`
7. `relationships.md`
8. `foreshadowing.md`

젠스파크: `WRITE_RULES.md` + `briefs/CHAPTER_NN.md`가 주입력. 부 전체 줄거리 전문은 넣지 않는다.

## 문체

- 한국어 문어체 무협. 한자 병기 가능.
- 감각·내면 독백 비중. 설명 덤프·상태창 남발 금지.
- 유튜브 낭독 호흡: 짧은 문장과 긴 문장 혼용.

## 금지

- 사망 인물 설명 없이 재등장
- 정보 격리 위반 (모르는 사실을 아는 척)
- 경지·나이·계절·장소가 바이블과 충돌하는 즉흥 설정
- 복선을 심고 `foreshadowing.md`에 안 적기

## 새 장 작성 체크

1. 시점 나이·계절을 `timeline.md`에 맞춤
2. 이 장 사건 ID가 `events.md`에 있는지 확인
3. 등장 인물 상태(생존/사망/납치/정보) 확인
4. 무공·경지 `martial_arts.md` 대조
5. 장소 이동에 시간 배분
6. 새/회수 복선 → `foreshadowing.md` 갱신
7. 젠스파크: 신규 사건으로 분량 채우지 말 것 (`WRITE_RULES.md`)
