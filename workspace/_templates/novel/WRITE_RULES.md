# {TITLE} — 젠스파크 작성 규칙

젠스파크 **한 채팅 = 한 장**. 이 파일 + 해당 `briefs/CHAPTER_NN.md` + 직전 장 끝부분만 넣는다.  
부 전체 줄거리·앞장 전문은 넣지 않는다.

## 합본 전 (필수)

BRIEF에 아래가 **실제 문장으로** 채워져 있어야 한다.  
자리표시·공란이 있으면 합본·생성하지 말 것.

1. 직전 장에서 이어질 상태
2. 비트 8~12
3. 종료 훅 한 줄
4. 직전 장 끝 **800~1,500자**
5. 등장 호칭·관계 2~6줄 (`characters.md` 전문 금지)
6. 숫자·고유명사 손채움
7. 정보 격리 한 줄 이상
8. 장소: 시작 → 끝
9. 이 장 사건 ID만
10. 이번에 심거나 만질 복선 Fxx만

양식: `briefs/_TEMPLATE.md`

## 분량

- 목표: 본문 **9,000~11,000자**
- 부족해도 **신규 사건·신규 주요 인물·새 조직·사망·자결·납치**로 채우지 말 것

## 반드시 따를 것

1. BRIEF 비트 번호 순서대로만
2. 호칭·관계는 BRIEF·인물 발췌만
3. 숫자·고유명사는 BRIEF 고정
4. 정보 격리 준수
5. 다음 장 사건 선취 금지

## 쓰기 전 승인

- 새 이름 있는 인물 / 새 문파
- 대규모 전투, 배신 확정, 사망·자결·납치
- 기존 사건 결과·시간 순서 변경
- `events.md`에 없는 사건 ID

## 출력

```
<<<CHAPTER_START>>>
(제목 한 줄)
(본문)
<<<CHAPTER_END>>>
```

2. `briefs/CHAPTER_NN.md`
3. 필요 인물만 발췌
4. 직전 장 끝 800~1,500자
