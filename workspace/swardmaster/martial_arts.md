# 검신귀환록 — 무공 체계

## 경지 (상위)

| 경지 | 설명 | 보유자 예시 |
|------|------|-------------|
| 화경(化境) | 고수 상위 | 현생 진무한: 18세 무렵 **화경 아래턱** · 내공 **열두 해** 치(7~8장) |
| 현경(玄境) | 화경 위 | 전생 진무한: 화경을 넘어 현경에 발 걸침 |

- 강호 속어: 삼류·이류(왕삼도 = 이류급).
- 문파 서열: 정통/방계 → 이대 → 원로. (경지와 별개)

## 주요 무공

| 이름 | 소속/출처 | 비고 |
|------|-----------|------|
| 자하신공 / 자하검법 | 화산 정통 | |
| 한매심법 (+ 역류법) | 진무한 자작 | 기운 은폐·감기옥 금색 억제 |
| 낙매십삼검 → 검신무 | 진무한 | 매화점·매화락·매화절·매화영·**매화귀토**(제7식) |
| 일검단천 | 검성/검총 | 자하검법과 재구성 |
| 백야 관련 | 한백강 | 미개화 무혼 — 눈에 옅은 백야 빛 |

## 발현·특수 규칙

1. **은빛**: 검신·눈·무혼 개화·소검 공명 시.
2. **감기옥 근기색**: 회색~청~금. 금색은 화산 300년 **세 번**(시조·검성·진무한 순간).
3. **검 없이 벤다**: 전생 현경 묘사. 현생은 소검 중심 — 현생에서 함부로 재현하지 말 것.
4. **무혼 개화**: 회귀자가 사후 결과를 마주하고 의지로 다시 쓸 때 → 수련 속도 **2배**(7장).
5. **천마의 눈**: 미래 단편. 파편이 왕삼도·한백강·임소천 등에 분산.

## 독

- **혈응독**: 무형·무취. 사형제의 정으로 마신 술에만 반응. 20년 조제. 만독불침도 뚫음.
- **은침**: 심맥 파괴.

## 미수득 기연 (계획)

- 폐약초원 백년하수오
- 무한 마룡 여기
- 사천 검혼 파편
