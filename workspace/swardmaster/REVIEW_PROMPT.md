# 검신귀환록 — 검수 프롬프트

아래 블록을 Agent에게 그대로 붙여 넣는다.  
대상 범위를 좁히면 정확도가 올라간다. (예: 「이번엔 1차만」「011~012만」)

---

## 전체 검수 (권장: 7단계로 나눠 실행)

```
프로젝트 `검신귀환록/` 전체를 읽어라.
기준: events.md, chapter_map.md, world.md, characters.md, martial_arts.md, timeline.md, relationships.md, foreshadowing.md
대상: 1부·2부 본문(및 chapters/*.md)

아래를 **단계별로** 검사하고, 각 이슈마다
- 장 번호
- 인용(짧은 구절)
- 충돌 내용
- 수정 제안
을 적어 `review.md` 상단에 날짜와 함께 저장해라.
이미 아는 사전 메모와 중복되면 "기존 메모 확인"이라고만 적어라.

### 0차 — 사건 순서·장 맵 (신규)
events.md 선후 vs 본문. chapter_map 제목 vs 본문 주제. 사망·납치 시점. 본문에만 있는 신규 사건(WARNING).

### 1차 — 설정 충돌만
세계관·세력·소속·정통/방계·서열·고유명사 충돌.

### 2차 — 등장인물만
나이, 생존/사망/납치, 이름·한자, 정보 격리(relationships.md), 말투·성격 붕괴. (남궁준=사촌 형뻘)

### 3차 — 시간순만
연표, 계절, 나이 진행(1부·2부 나이 충돌 포함), 「이십 년/사십 년」 표기, 장소 이동 시간.

### 4차 — 무공만
경지, 초식 이름, 검기/은빛/감기옥, 미습득 기연 무단 사용, 전투력 붕괴.

### 5차 — 복선만
foreshadowing.md의 미회수·진행중. 심어놓고 잊힌 것, 잘못 회수된 것.

### 6차 — 캐릭터 성장만
진무한·한백강·서령란의 태도 변화 곡선이 장 흐름과 맞는지. 급변·붕괴.

### 7차 — 결말·미회수만
지정 부 기준으로 끝까지 읽고, 회수되지 않은 내용만 목록화.
수정 우선순위(치명/중요/경미)를 매겨라.
```

## 빠른 검수 (한 번에 · 정확도↓)

```
검신귀환록 프로젝트 전체를 읽고 검사하라.

1. 세계관 충돌
2. 등장인물 설정 충돌
3. 무공 체계 충돌
4. 연표 오류
5. 사망한 인물 등장
6. 떡밥 미회수
7. 복선 회수 오류
8. 전투력 붕괴
9. 장소 이동 오류
10. 말투 변화
11. 성격 붕괴
12. 인과관계 부족
13. 같은 설명 반복
14. 모순되는 대사
15. 수정 방법까지 제안

결과는 review.md에 저장해라.
```

## 문예 리뷰 (추상 품질 · 별도)

설정 검수와 **섞지 말 것**.

```
chapters 지정 범위를 낭독 스크립트 관점으로 읽어라.
평가만 하고 설정 모순은 다루지 마라.

- 장면별 긴장감
- 감정선·감동 지점
- 빌드업과 페이오프
- 악역(한백강 전생 / 노인)의 매력
- 유튜브 3시간 호흡에서 늘어지는 구간
- 개선 제안(구체적 장면 단위)

결과는 review.md의 「문예 리뷰」 섹션에 추가해라.
```
