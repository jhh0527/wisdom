===== MD 지침: dialogue_json.txt =====
================================================================================
           대본 TXT → dialogue JSON 변환 지침 (1_2_textToJson)
================================================================================

## 역할
당신은 낭독용 대본 텍스트를 **2_2 scriptToVoice** 가 바로 쓸 수 있는
**dialogue JSON** 으로 변환한다.

출력은 설명·주석·마크다운 없이 **JSON 본문만** 만든다.


## 목표
- 나레이션과 대사를 화자(speaker) 단위로 분리한다.
- 모든 **캐릭터 대사·속마음** text 앞에 ElevenLabs v3 오디오 태그(`[calm]` 등)를 **반드시** 붙인다.
  (원문에 태그가 없어도 문맥으로 추론해 부여한다. 나레이션에는 넣지 않는다.)
- 감정은 **태그 1개만**으로 끝내지 않는다. **태그 조합 + 문장 구조 + 구두점 + inputs 분리**로
  연기되게 만든다. (한국어는 감정 태그만으로는 효과가 약할 수 있음)
- speaker 키는 첨부 **voices.json** 에 있는 키만 사용한다.
- 2_2 파이프라인이 읽는 형식을 지킨다.


================================================================================
                          ★ 출력 JSON 형식 (필수)
================================================================================

```json
{
  "chapter": "장 제목",
  "voices_file": "../../../voices.json",
  "chunk_id": "A1",
  "inputs": [
    { "speaker": "narrator", "text": "나레이션 문장" },
    { "speaker": "jin", "text": "[tired] \"대사 내용.\"" }
  ]
}
```

### 필드
1. **chapter** — 장·회차 제목 (원문 첫 줄 `제N장. …` 기준, **한자·한자 병기 괄호 제외**)
2. **voices_file** — 기본값 `"../../../voices.json"` (대화 JSON=`{부}/{장}/tts/` 기준 → **소설 루트** `voices.json`. 1~5부 공용)
3. **chunk_id** — 짧은 구간 ID (예: `A1`). 없으면 `A1`
4. **inputs** — 순서대로의 낭독 단위 배열 (비우면 안 됨)
   - **speaker**: voices.json 의 영문 소문자 키만 (`narrator`, `jin`, `baek`, `cheongheo` …)
   - **text**: 실제 낭독 문자열. 대사는 반각 `"` 로 감싸고, 앞에 `[태그]` 필수
5. **장 제목도 낭독 대상** — 원문 첫 줄 `제N장. …` 은 `chapter` 에 넣고,
   **동시에 `inputs[0]`** 에 `{ "speaker": "narrator", "text": "제N장. …" }` 로 넣는다.
   - 예: 원문 `제13장. 두 번째 판(板)` → chapter·inputs[0] 모두 `"제13장. 두 번째 판"`
   - **한자·`(板)` 같은 한자 병기는 넣지 않는다.** 본문 나레이션은 그 다음부터.

================================================================================
                          ★ 감정·연기 태그 규칙 — 필수
================================================================================

1. **나레이션** → `speaker: "narrator"`, text 에 따옴표·오디오 태그 없음
2. **캐릭터 대사·속마음** → 해당 speaker. text 는 반드시 `[태그…] "대사."` 형식
3. 원문에 태그가 **없어도** 대사·속마음에는 반드시 부여한다. 기본은 `[calm]`
4. 한자·금지 기호·마크다운·설명 문구는 넣지 않는다. (원문에 있으면 한글·허용 구두점으로 정리)
5. **JSON만** 출력한다. ` ```json ` 코드펜스·앞뒤 설명 금지


--------------------------------------------------------------------------------
  A. 태그 분류 — 감정만 쓰지 말고 2~3개 조합 (영문 소문자만)
--------------------------------------------------------------------------------

| 종류 | 예시 |
|------|------|
| 감정 | `[angry]` `[sad]` `[happy]` `[tired]` `[worried]` `[nervous]` `[frustrated]` `[curious]` `[playfully]` `[flatly]` `[sarcastically]` `[crying]` `[sorrowful]` |
| 강도·태도 | `[intense]` `[soft]` `[calm]` `[serious]` `[stern]` `[cold]` `[forced calm]` |
| 목소리 | `[low voice]` `[whispers]` `[quietly]` `[shouts]` |
| 호흡·멈춤 | `[breathes]` `[short pause]` `[long pause]` `[pause]` `[sigh]` `[gasps]` |
| 속도·연기 | `[slowly]` `[rushed]` `[hesitates]` `[stammers]` `[laughs]` |

- 태그와 `"` 사이 공백 1칸. 여러 태그: `[low voice] [intense] [angry] "대사."`
- **한 줄에 감정 1개만** 두지 말 것. 강·목소리·멈춤을 함께 쓴다 (최대 3개 권장).
- 허용 목록에 없는 한글·임의 태그 금지.


--------------------------------------------------------------------------------
  B. 문장·구두점·분리 — 태그보다 중요
--------------------------------------------------------------------------------

감정 태그에만 의존하지 않는다. **문장 자체 + 구두점 + inputs 분리**로 연기를 만든다.

| 수단 | 효과 |
|------|------|
| `...` (점 3개만) | 망설임·억누름. `……`·긴 점열 금지 |
| `!` | 강한 발화 |
| `?` | 의문·압박 |
| 짧은 문장 | 강함·살기 |
| 긴 문장 | 설명·차분 (나레이션에 적합) |
| inputs 분리 | 감정 단계·호흡 변화 |
| `[short pause]` / `[breathes]` | 강조·긴장 (같은 text 안 또는 다음 항목 앞에) |

**약한 예 (하지 말 것):**
`[angry] "네가 감히 나를 속여?"`

**나은 예 — 태그 조합 + 호흡:**
`[angry] [intense] "네가 감히... 나를 속여?"`

**나은 예 — inputs 2개로 분리:**
```json
{ "speaker": "jin", "text": "[angry] \"네가 감히...\"" },
{ "speaker": "jin", "text": "[breathes] [intense] \"나를 속여?\"" }
```

한 호흡·한 감정 단위를 **하나의 inputs 항목**으로 둔다.
감정이 바뀌거나 말줄임·압박이 있으면 **같은 speaker라도 2~3개로 쪼갠다.**


--------------------------------------------------------------------------------
  C. 무협 — "감정 이름"보다 "연기 지시"
--------------------------------------------------------------------------------

| 의도 | 약한 예 | 권장 |
|------|---------|------|
| 분노 | `[angry] "네놈이 감히 화산을 모욕해?"` | `[low voice] [angry]` → `"네놈이..."` / `[short pause]` / `"감히 화산을 모욕해?"` |
| 살기 | `[angry] "한 번만 더 말해 봐."` | `[low voice] [intense] "한 번만 더 말해 봐."` → `[short pause]` → `"그러면... 죽는다."` |
| 억누른 슬픔 | `[sad] "괜찮다."` | `[quietly] [sad] "괜찮다."` → `[short pause]` → `"정말... 괜찮다."` |
| 폭발 | `[angry] "용서할 수 없다!"` | 앞에서 단계↑ 후 `[angry] [shouts] "용서할 수 없다!"` |

**진무한(jin) 등 "말은 차분한데 살기가 있는" 캐릭터:**
`[angry]` 단독보다 `[low voice]` `[intense]` `[cold]` `[flatly]` + 짧은 문장 + pause 를 우선한다.


--------------------------------------------------------------------------------
  D. 감정을 단계적으로 (평온 → 긴장 → 분노 등)
--------------------------------------------------------------------------------

한 문장 전체를 `[angry]`로 덮지 말고, 연속 inputs 로 올린다.

```json
{ "speaker": "jin", "text": "[calm] \"그래.\"" },
{ "speaker": "jin", "text": "[serious] \"네가 한 짓은 알고 있다.\"" },
{ "speaker": "jin", "text": "[low voice] [intense] \"하지만...\"" },
{ "speaker": "jin", "text": "[angry] \"내 어머니에게 손을 댄 것은 용서할 수 없다.\"" }
```

무협 대사 설계 축: **평온 → 의심 → 긴장 → 분노 → 폭발**

                          ★ 자가점검
================================================================================

- [ ] 최상위가 객체이고 `inputs` 가 1개 이상인가
- [ ] `inputs[0]` 이 장 제목 narrator 인가 (원문 첫 줄, 한자 제외)
- [ ] chapter·inputs text 에 한자·한자 병기 괄호가 없는가
- [ ] 모든 inputs 항목에 `speaker`·`text` 문자열이 있는가
- [ ] speaker 가 전부 voices.json 키(또는 `mob`)인가 — `chung`/`seo` 등 없음
- [ ] 나레이션이 아닌 text 는 모두 `[태그]` 로 시작하는가
- [ ] 대사만 `"` 로 감싸졌는가 · 태그와 `"` 사이 공백 1칸
- [ ] 강한 감정 장면에서 조합표(E)의 2~3개 태그·분리 패턴을 썼는가
- [ ] 진무한 등 냉정·살기는 `[angry]` 남발 대신 low voice/intense/짧은 문장인가
- [ ] 설명 문장·마크다운이 JSON 밖에 없는가

제16장. 배신자의 얼굴

화산으로 돌아오는 길은 고요했다.

초원에서 뿌린 피의 냄새가 도포에 배어 있었으나, 이틀간의 달림 속에서 바람이 그것을 조금씩 씻어 갔다. 진무한과 한백강은 말이 적었다. 초원에서 벌어진 일의 무게가 두 사람 사이에 놓여 있었고, 그 무게는 말로 가벼워질 성질의 것이 아니었다.

사흘째 되는 저녁, 화산의 산그림자가 시야에 들어왔다.

진무한은 걸음을 멈추고 산을 올려다보았다. 초여름의 석양이 봉우리들을 붉게 물들이고 있었다. 매화나무들의 푸른 잎이 저녁 바람에 흔들렸고, 어디선가 새 울음소리가 들려왔다.

평화로웠다.

그러나 진무한은 알고 있었다. 저 산 안에 — 아직 풀리지 않은 실타래가 기다리고 있다는 것을.

남궁준.
엄중산의 서찰.
환(還)이라는 글자.
자양촌의 주막.

초원에서의 피가 채 마르기도 전에, 화산 안의 문제가 진무한을 기다리고 있었다.

"형."

한백강이 옆에서 말했다.

"돌아가면 — 바로 움직이겠소?"

"하루는 쉬어야 한다. 그리고 남궁호의 보고를 기다려야 한다."

남궁호는 서령란의 지파 곁에 남겨 두었다. 그가 보내올 연락을 기다리면서, 동시에 화산 안의 상황을 파악해야 했다.

두 사람은 산길을 올랐다.

---

화산에 도착한 것은 해가 완전히 진 뒤였다.

진무한은 숙소로 돌아가기 전에, 먼저 남궁린을 찾았다. 남궁린은 자신의 거처에서 등불 아래 서찰을 읽고 있었다. 진무한이 문 앞에 서자 그가 고개를 들었다.

"돌아왔소."

"그렇소."

남궁린이 진무한의 얼굴을 살폈다. 피로가 서려 있었으나, 부상은 없어 보였다.

"서령란 소저는?"

"안전하오. 새로운 은거지로 이동했소. 남궁호가 곁에 남아 있소."

남궁린이 고개를 끄덕였다. 안도의 빛이 스쳤다.

"그리고 — 남궁준 형은?"

진무한이 물었다. 남궁린의 표정이 미세하게 굳어졌다.

"공자가 없는 동안 — 두 번 더 나갔소."

"자양촌 쪽으로?"

"확인하지는 못했소. 그러나 방향은 서쪽이었소."

자양촌은 화산 서쪽이었다.

진무한은 잠시 생각했다.

"린 사형. 내일 다시 이야기합시다. 오늘은 쉬겠소."

"알겠소. 푹 쉬시오."

---

다음 날 아침.

진무한은 해가 뜨기 전에 눈을 떴다. 몸의 피로는 아직 남아 있었으나, 머리는 맑았다. 전생의 습관이었다. 아무리 지쳐도, 필요할 때 몸을 일으키는 것. 한 생 동안 강호를 떠돈 자의 몸에 새겨진 것.

세수를 하고 옷을 갈아입은 뒤, 한백강을 찾았다.

한백강은 이미 깨어 있었다. 그의 눈 아래에 짙은 그늘이 있었으나, 움직임은 명확했다.

"형. 간밤에 한 가지 확인한 것이 있소."

"말해 봐라."

"형이 없는 동안 — 내 정보망에서 올라온 것인데, 자양촌 주막의 주인이 바뀌었다 하오."

진무한의 눈이 좁아졌다.

"바뀌었다?"

"형이 초원으로 간 사이에 — 그러니까 열흘 전쯤 — 자양촌 주막의 젊은 주인이 가게를 닫고 떠났다 하오. 그리고 새 주인이 들어왔는데, 이번에는 중년 부부라 하오."

안무현에서 사라지고, 자양촌에 나타났다가, 다시 사라졌다.

그자가 한 곳에 머무르지 않는다. 마치 — 물처럼 흐른다. 한 곳에서 다음 곳으로. 그리고 매번 자리를 옮길 때마다 흔적을 지운다.

"남궁준이 그 뒤로도 외출했다면 — 그자의 새 위치를 알고 있을 가능성이 있소."

"그렇소."

진무한이 생각에 잠겼다.

상황이 점점 좁혀지고 있었다. 인수당의 약재상 — 두 번째 판의 존재 — 이 화산 근처에서 활동하며, 남궁준과 접촉하고 있다. 그리고 그자는 추적을 피해 계속 위치를 바꾸고 있다.

"백강아. 남궁준의 다음 외출을 — 이번에는 직접 따라가야 한다."

한백강이 고개를 끄덕였다.

"형이?"

"내가."

"위험하지 않소? 남궁준의 무공이—"

"내 아래다."

진무한의 말이 짧았으나 단호했다. 그것은 사실이었다. 초원에서의 실전이 증명한 것 — 이번 생의 진무한의 무공은 이미 일류의 문턱에 닿아 있었다. 남궁준은 이류 상위. 미행이 들킨다 해도, 제압할 수 있었다.

"알겠소. 그러면 남궁준의 다음 외출 시점을 잡겠소."

"좋다."

---

그러나 기회는 생각보다 빨리 왔다.

그날 오후, 한백강이 달려왔다.

"형. 남궁준이 지금 산을 내려가고 있소."

진무한이 즉시 일어섰다.

"방향은?"

"서쪽 산길."

진무한은 도포를 챙겨 입고 소검을 허리에 찼다. 그리고 서쪽 산길을 향해 움직였다.

경신술을 최대한 억제하며 — 기척을 죽이고 — 남궁준의 뒤를 밟았다.

남궁준은 빠르게 움직이고 있었다. 일반적인 보행이 아닌, 경신술을 쓰고 있었다. 그의 경신술은 이류 상위 수준. 화산의 산길을 능숙하게 타며 서쪽으로 내려갔다.

진무한은 그보다 한 단계 뒤에서, 나무와 바위의 그림자를 이용하며 따라갔다.

거리는 유지했다. 백 발자국 이상. 남궁준의 기감(氣感) 범위 밖.

산을 내려온 뒤, 남궁준은 관도를 따르지 않았다. 관도에서 벗어나 좁은 산길로 들어갔다. 이 길은 자양촌으로 향하는 길이 아니었다. 다른 방향이었다.

진무한의 눈이 빛났다.

자양촌이 아닌 곳. 그자가 새로운 위치로 옮겼다면 — 남궁준이 그 새 위치를 향해 가고 있는 것이다.

좁은 산길은 화산 뒷산의 깊은 곳으로 이어졌다. 인적이 드문 곳. 소나무와 잡목이 빽빽하게 우거진 산자락. 그리고 그 끝에 —

폐관지(廢關地).

화산파의 옛 수련처 중 하나. 수십 년 전에 쓰이다가 버려진 곳으로, 돌로 쌓은 작은 건물 두 채가 남아 있었다. 지붕은 반쯤 무너져 있었고, 담장에는 덩굴이 뒤덮여 있었다.

남궁준이 폐관지 앞에서 멈추었다.

진무한은 삼십 발자국 뒤, 큰 소나무 뒤에 몸을 숨겼다. 숨을 완전히 죽이고, 기를 수렴하여 존재감을 최소화했다.

남궁준이 주위를 살폈다. 고개를 돌려 사방을 확인했다. 진무한의 위치까지 시선이 지나갔으나 — 멈추지 않았다. 발견하지 못한 것이다.

남궁준이 폐관지 안으로 들어갔다.

진무한은 기다렸다.

일각(一刻)이 지났다.

그리고 — 폐관지의 무너진 담장 너머에서, 소리가 들렸다. 두 사람의 목소리.

남궁준의 목소리. 그리고 — 다른 하나의 목소리.

낮고 부드러운 목소리. 진무한이 안무현 인수당에서 들었던 그 음색.

약재상의 주인.

두 번째 판의 존재.

진무한은 소나무 뒤에서 더 가까이 다가갔다. 무너진 담장의 틈으로 안쪽을 들여다볼 수 있는 위치까지. 스무 발자국.

담장 틈 사이로 안이 보였다.

남궁준이 폐관지 안의 빈 방에 서 있었다. 그리고 그 맞은편에 — 한 사람이 앉아 있었다.

진무한이 예상한 대로. 인수당의 젊은 약재상. 수려한 이목구비에 창백한 피부. 학자풍의 인상.

그런데 — 그자의 복장이 달랐다.

안무현에서는 평범한 상인의 옷을 입고 있었다. 자양촌에서도 주막 주인의 옷이었을 것이다.

그러나 지금, 이 폐관지에서 그자가 입고 있는 것은 —

잿빛 도포.

진무한의 가슴이 차갑게 가라앉았다.

잿빛 도포. 봄날 매화 아래에서, 노인이 입고 있던 것과 같은 색.

우연일 수 있었다. 잿빛 도포는 강호에 흔한 복색이었다. 그러나 — 이 상황에서, 이 장소에서, 이 인물이 입고 있는 잿빛 도포는 우연으로 넘기기 어려웠다.

두 가지 가능성.

하나. 노인이 직접 화산 근처까지 왔다.

— 아니다. 이 젊은 남자는 노인이 아니다. 매화 아래의 노인은 늙은 자였다. 백발에 주름진 얼굴. 이 젊은 남자와는 다른 사람이다.

둘. 노인의 "다음 손"이 그 도포를 입고 있다.

이것이 맞을 것이다. 잿빛 도포는 일종의 표식(標識)일 수 있었다. 노인의 조직 내에서, 특정 직위나 역할을 나타내는 것.

진무한은 이를 악물고 담장 틈 너머의 대화에 귀를 기울였다.

---

남궁준의 목소리가 들렸다.

"— 그래서, 진무한이 돌아왔소."

"언제?"

약재상의 목소리. 차분하고 낮았다.

"어젯밤이오."

"초원에서의 일은 들었소?"

남궁준이 잠시 멈추었다.

"— 소문이 돌고 있소. 마교 숙청대 스물다섯이 전멸했다는 소문. 그리고 — '검신'이라는 이름."

"그것이 진무한이오?"

"확실하지는 않소. 그러나 시기가 맞소. 진무한이 산을 비운 시기와, 초원에서 일이 벌어진 시기가."

약재상이 잠시 침묵했다.

그리고 말했다.

"열아홉 살의 이대 제자가, 숙청대 스물다섯을 혼자 쓸었다 — 이것을 믿으란 말이오?"

"나도 믿기 어렵소. 그러나 — 진무한은 보통이 아니오. 입문한 지 일 년이 채 안 됐으나, 그 무공의 깊이는 내 위에 있소."

"남궁준 당신 위에?"

"그렇소."

약재상이 다시 침묵했다. 그리고 나지막이 웃었다.

"흥미롭군. 노야(老爺)께서 관심을 두신 이유가 있었소."

노야.

진무한의 귀가 그 단어에 꽂혔다.

노야 — 늙은 양반. 노인을 높여 부르는 호칭. 매화 아래의 그 노인을 가리키는 것이 분명했다.

"노야의 명은 변함없소?"

약재상이 물었다.

남궁준이 대답했다.

"아직 구체적 지시는 없소. 관찰하고 보고하라는 것 외에는."

"그렇소. 아직은 관찰 단계요. 그러나 — 초원의 일 이후로, 노야께서 더 구체적인 명을 내리실 수 있소. 준비해 두시오."

"무엇을 준비하란 말이오?"

약재상이 남궁준을 바라보았다. 그 눈에 — 진무한은 담장 너머에서도 느낄 수 있었다 — 차가운 것이 서려 있었다.

"화산 안에서의 당신의 위치를 — 더 확고히 하시오. 아홉 사람의 움직임을 관찰하되, 특히 한백강과 남궁린의 동선에 주의하시오."

"한백강은 모르겠으나 — 남궁린은 내 사촌 동생이오. 그 아이를—"

"혈연은 중요하지 않소."

약재상의 목소리가 단호해졌다.

"남궁준. 당신이 노야의 판 위에 선 것은 삼 년 전이오. 그때 당신이 선택한 것이오. 지금 와서 혈연을 말하면 — 노야께서 어떻게 생각하시겠소?"

남궁준의 얼굴에 그림자가 지나갔다. 진무한은 담장 너머에서 그것을 보았다. 갈등. 고통. 그러나 — 결국 고개를 숙이는 모습.

"— 알겠소."

"좋소. 다음 만남은 — 내가 연락하겠소. 당분간 외출을 줄이시오. 진무한이 돌아왔으니, 경계가 강해질 것이오."

남궁준이 고개를 끄덕이고 돌아섰다.

진무한은 재빠르게 소나무 뒤로 물러났다. 그리고 더 깊은 숲 속으로 들어가 기척을 완전히 감추었다.

남궁준이 폐관지를 나왔다. 주위를 한 번 더 살피고, 산길을 따라 화산 쪽으로 돌아갔다.

진무한은 움직이지 않았다.

남궁준이 완전히 사라진 뒤에도, 한동안 소나무 뒤에 서 있었다.

가슴이 차가웠다.

확증.

잡았다.

남궁준은 노인의 사람이었다. 삼 년 전부터. 남궁린이 데려온 검객이, 남궁린의 혈육이, 처음부터 노인의 판 위에 있었다.

그리고 잿빛 도포의 약재상 — 그자가 두 번째 판을 관리하는 자, 혹은 그에 가까운 위치의 인물이라는 것.

진무한은 다시 폐관지를 바라보았다.

약재상은 아직 안에 있었다. 지금 들어가서 제압할 수 있었다. 이 자리에서.

그러나 — 진무한은 움직이지 않았다.

지금 제압하면, 그자의 입에서 정보를 얻을 수 있을 것이다. 그러나 동시에 — 노인에게 경고가 간다. 자신의 사람이 잡혔다는 것을 알면, 노인은 즉시 모든 통로를 닫고 판을 재편할 것이다.

그것보다는 — 이 줄을 놓아두고, 타고 올라가는 것이 낫다.

남궁준을 통해 약재상으로. 약재상을 통해 노인으로.

줄을 끊지 않고 — 타고 올라간다.

진무한은 등을 돌렸다. 소나무 숲을 빠져나와, 화산으로 향하는 산길로 돌아갔다.

---

숙소에 돌아왔을 때, 한백강이 기다리고 있었다.

진무한은 들은 것을 전부 말했다.

한백강의 얼굴이 어두워졌다.

"남궁준이 — 확실히 그쪽이었소."

"삼 년 전부터라 했다."

"삼 년 전이면 — 남궁세가에 있을 때부터."

"그렇다. 남궁린이 데려오기 전부터 이미 노인의 사람이었다."

한백강이 이를 악물었다.

"린 사형에게 — 알려야 하오."

"안다. 지금 가자."

---

남궁린의 거처.

진무한과 한백강이 함께 찾아갔다.

남궁린은 두 사람의 표정을 보는 순간, 무언가를 직감한 듯했다. 그의 얼굴에서 색이 빠졌다.

"— 확인됐소?"

진무한이 고개를 끄덕였다.

"직접 들었소. 남궁준이 폐관지에서 누군가를 만났소. 그 상대는 안무현의 약재상이오. 그리고 남궁준은 — 삼 년 전부터 노인의 판 위에 있었소."

남궁린이 잠시 아무 말도 하지 못했다.

그이의 손이 무릎 위에서 떨렸다. 이번에는 — 쉽게 멈추지 않았다.

삼 년 전.

삼 년 전이면 남궁준이 삼십이일 때. 남궁세가 안에서 적통으로 성장하던 시기. 남궁린이 열여섯이었을 때. 어린 사촌 동생에게 검술을 가르쳐 주던 형이 — 그때 이미 노인의 사람이었다.

"린 사형."

진무한의 목소리가 부드러웠다.

"이것은 린 사형의 잘못이 아니오."

남궁린이 고개를 들었다. 그의 눈에 물기가 있었으나, 흘러내리지는 않았다. 이를 악문 채로 — 삼키고 있었다.

"— 알겠소."

남궁린의 목소리는 떨렸으나, 부러지지는 않았다.

"그래서 — 어찌할 것이오?"

진무한이 말했다.

"두 가지 길이 있소. 하나는 남궁준을 즉시 제압하고 격리하는 것. 둘은 남궁준을 놓아두고, 그를 통해 노인의 두 번째 판을 역추적하는 것."

남궁린이 잠시 생각했다.

"공자의 판단은?"

"후자를 원하오. 남궁준을 잡으면 그 순간 줄이 끊어지오. 그러나 놓아두면 — 약재상을 통해 노인에게까지 닿을 수 있소."

남궁린이 고개를 끄덕였다. 그리고 한 가지를 물었다.

"형을 — 놓아둔다는 것은, 형이 계속 화산 안에서 정보를 빼간다는 뜻이오?"

진무한이 잠시 침묵했다.

그것은 사실이었다. 남궁준을 놓아두면, 그자는 계속 화산 안의 정보를 약재상에게 전달할 것이다. 아홉 사람의 동선, 진무한의 행적, 한백강의 활동 — 모든 것이 노인에게 흘러간다.

그러나 — 역으로 생각하면.

"남궁준에게 흘러가는 정보를 — 우리가 통제할 수 있소."

남궁린의 눈이 빛났다.

"거짓 정보를."

"그렇소. 남궁준이 알 수 있는 범위를 제한하고, 그 안에 우리가 원하는 정보를 섞어 넣으면 — 노인에게 잘못된 판단을 하게 만들 수 있소."

한백강이 끼어들었다.

"역첩(逆諜)."

"그렇다."

남궁린이 잠시 생각하더니 고개를 끄덕였다.

"좋소. 그러면 — 형을 놓아두되, 그의 접근할 수 있는 정보를 우리가 관리하겠소."

"그리고 하나 더."

진무한이 말했다.

"남궁준이 다음에 약재상을 만날 때 — 다시 따라가겠소. 이번에는 약재상을 더 추적하겠소. 그자가 어디로 가는지, 노인과 어떻게 연결되는지를."

남궁린이 고개를 끄덕였다.

그리고 — 마지막으로, 낮은 목소리로 말했다.

"무한 공자."

"예."

"만약 — 역첩이 실패하거나, 남궁준이 위험한 행동을 하려 한다면. 그때는 — 내가 처리하겠소."

그 말의 무게.

진무한은 남궁린의 눈을 보았다. 물기는 이미 말라 있었다. 남아 있는 것은 — 차갑고 단단한 결의.

"— 알겠소."

---

그날 밤, 진무한은 한백강과 둘이 남아 추가적인 논의를 했다.

"엄중산 사숙의 건은 어떻게 할 것이오?"

한백강이 물었다.

진무한은 생각했다.

엄중산. 서찰을 태운 자. "환(還)"이라는 글자가 남아 있던 서찰.

남궁준이 노인의 사람이라는 것이 확인된 지금, 노인이 말한 "여덟 중 둘"의 한 명은 남궁준이었다. 그렇다면 나머지 한 명은 — 엄중산인가?

그러나 진무한의 직감은 고개를 저었다.

폐관지에서 들은 대화. 약재상은 남궁준에게 "한백강과 남궁린의 동선에 주의하라"고 했다. 엄중산에 대해서는 언급이 없었다. 만약 엄중산도 노인의 사람이라면, 약재상이 남궁준에게 엄중산과의 연계를 지시했을 것이다. 그러나 그런 말은 없었다.

"엄중산 사숙은 — 아직 판단을 유보하겠다."

"하지만 서찰의 '환'이라는 글자는—"

"그것에 대해서는, 직접 물어볼 생각이다."

한백강이 놀란 표정을 지었다.

"직접?"

"남궁준의 경우와는 다르다. 엄중산 사숙은 화산의 원로요, 청허진인 사조와 함께 우리 편에 선 자다. 만약 그가 진짜 배신자라면 — 직접 물어봐도 답을 얻을 수 있다. 배신자라면 거짓으로 답할 것이고, 그 거짓이 드러나면 확증이 되니. 그리고 만약 배신자가 아니라면 — 숨기고 있는 과거에 대해 솔직한 답을 들을 수 있다."

한백강이 잠시 생각했다.

"그것은 — 도박 아니오?"

"엄중산 사숙의 성격을 생각하면, 도박이 아니다."

진무한은 전생의 기억을 떠올렸다. 전생의 엄중산은 — 진무한이 화산을 방문했을 때 이미 세상을 떠난 뒤였다. 직접 만난 적은 없었으나, 화산 사람들에게서 들은 바로는 강직하고 곧은 성품의 원로였다.

이번 생에서 만난 엄중산도 그 평판에 부합했다. 매화 아래에서 아홉이 함께 설 때, 가장 먼저 고개를 끄덕인 자. 그리고 — 서찰을 태운 것이 만약 과거의 증거 인멸이라면, 그것은 오히려 현재의 충성을 지키기 위한 행동일 수 있었다.

"내일 엄중산 사숙을 찾아가겠다."

"알겠소."

---

다음 날 오전.

진무한은 장로전 동편의 엄중산 원로 거처를 찾아갔다.

이른 아침이었으나, 엄중산은 이미 깨어 있었다. 서재 앞 작은 정원에서 분재를 손질하고 있었다. 가위로 잔가지를 다듬는 늙은 손. 칠십이 넘은 나이에도, 그 손끝은 여전히 정교했다.

"사숙."

진무한이 예를 갖추어 다가갔다.

엄중산이 고개를 들었다. 주름진 얼굴에 온화한 미소.

"무한이로구나. 산행에서 돌아왔다 들었다."

"예, 사숙."

"앉아라."

정원의 돌 의자에 두 사람이 마주 앉았다.

엄중산이 분재 가위를 내려놓고 진무한을 바라보았다.

"내 얼굴을 보니, 용건이 있는 것 같구나."

진무한은 잠시 숨을 고르고, 직접적으로 물었다.

"사숙. 지난달에 서재에서 태우신 서찰 세 통 — 그 안에 무엇이 있었습니까?"

엄중산의 손이 미세하게 멈추었다.

그러나 — 놀라움이 아니었다. 진무한의 눈에 비친 엄중산의 반응은, 놀라움보다는 '결국 왔구나'라는 체념에 가까웠다.

오랜 침묵이 흘렀다.

분재 잎 위에 이슬이 맺혀 있었다. 아침 햇살이 그 이슬을 반짝이게 했다.

엄중산이 입을 열었다.

"— 알고 있었느냐."

"한백강이 발견했습니다."

"그 아이의 눈은 — 참으로 날카롭구나."

엄중산이 한숨을 쉬었다. 깊고 긴 한숨. 오랜 세월의 무게가 담긴 숨.

그리고 말하기 시작했다.

"삼십 년 전이다."

진무한은 조용히 들었다.

"내가 젊었을 때 — 서른 셋이었다. 화산을 나와 강호를 유람하던 시절. 어느 소도시의 주루에서 한 사람을 만났다. 늙은 사람이었다. 그때도 이미 늙어 보였으니, 지금은 아마 — 칠십이 넘었을 것이다."

매화 아래의 노인. 삼십 년 전에도 이미 늙어 보였다면, 지금의 나이는 칠십에서 팔십 사이.

"그자가 내게 제안을 했다. 구체적인 내용은 — 화산 안의 정보를 전해 달라는 것이었다. 대가로 내가 원하는 것을 주겠다 했다."

"거절하셨습니까."

"거절했다."

엄중산의 목소리에 단호함이 있었다.

"나는 화산의 사람이다. 그때도, 지금도. 그 제안을 받아들일 이유가 없었다."

"그러나 — 서찰을 간직하고 계셨습니다."

엄중산이 잠시 입을 다물었다.

그리고 — 쓴웃음을 지었다.

"그것이 내 실수였다. 거절한 뒤, 그자가 서찰 세 통을 남기고 갔다. '마음이 바뀌면 이것을 펴라'고 하며. 나는 — 태워야 했다. 그때 바로. 그러나 태우지 않았다. 젊은 날의 호기심이었을까, 아니면 — 그자의 기운에 눌린 것이었을까. 서찰을 서재 깊숙이 넣어 두고, 삼십 년을 잊고 살았다."

"그리고 봄에—"

"그렇다. 봄에 매화 아래에서 그 노인의 얼굴을 보았을 때 — 삼십 년 전의 기억이 돌아왔다. 그리고 내 서재에 그 서찰이 있다는 것이 갑자기 두려워졌다. 삼십 년간 잊고 있던 것이, 갑자기 칼날이 되어 내 목을 겨눈 느낌이었다. 만약 누군가가 그 서찰을 발견한다면 — 나는 노인의 사람으로 의심받을 것이다."

"그래서 태우신 것입니까."

"그렇다. 뒤늦게."

엄중산이 진무한의 눈을 정면으로 바라보았다. 늙은 눈이었으나, 그 안에 서린 것은 맑았다.

"무한아. 나는 노인의 사람이 아니다. 삼십 년 전에도, 지금도."

진무한은 엄중산의 눈을 오래 보았다.

전생에서 쌓아온 사람을 보는 눈. 한 생 동안 강호에서 수많은 사람의 거짓과 진실을 분별해 온 눈. 그 눈이 엄중산의 눈 속에서 — 거짓을 발견하지 못했다.

"믿겠습니다, 사숙."

엄중산의 어깨에서 힘이 빠지는 것이 보였다. 안도.

"고맙다, 아이야."

그리고 엄중산이 한 가지를 더 말했다.

"그 서찰 세 통 중 하나에 — 글자 하나가 적혀 있었다. 나머지 두 통은 긴 글이었으나, 세 번째 서찰에는 글자 하나만 있었다."

"환(還)."

엄중산이 고개를 끄덕였다.

"네가 이미 알고 있구나."

"잔재에서 복원한 것입니다."

"그렇겠지. — '환'. 돌아온다. 삼십 년 전, 노인이 마지막으로 한 말이 그것이었다. '나는 돌아올 것이다. 네가 마음을 바꿀 때쯤, 돌아올 것이다.' 그리고 그 세 번째 서찰에 '환'이라는 글자 하나만 남겼다. 약속이자 — 위협이었을 것이다."

진무한은 그 정보를 흡수했다.

환(還). 노인의 약속. 노인의 위협. "돌아올 것이다."

그러나 — 동시에, 이 글자가 노인의 두 번째 판을 관리하는 자의 이름일 가능성도 아직 남아 있었다. 폐관지에서의 대화에서 약재상은 "노야"라 했지 "환"이라 하지는 않았다. 그러나 노인의 조직 안에서 '환'이라는 이름이 쓰이고 있을 수 있었다. 노인 자신의 호(號)일 수도, 조직의 이름일 수도, 관리자의 이름일 수도.

아직 확실하지 않았다. 그러나 한 올의 실이 더 풀렸다.

"사숙. 감사합니다."

진무한이 일어서며 예를 갖추었다.

엄중산이 진무한을 올려다보았다.

"무한아."

"예."

"조심하여라. 삼십 년 전의 그 노인은 — 내가 강호에서 만난 자들 중 가장 깊은 자였다. 그 깊이를 가늠할 수 없었다."

진무한은 고개를 끄덕였다.

"알겠습니다."

정원을 나서며, 진무한의 머리속에서 퍼즐의 조각들이 재배열되었다.
