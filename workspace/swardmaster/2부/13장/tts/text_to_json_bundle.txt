===== MD 지침: dialogue_json.txt =====
================================================================================
           대본 TXT → dialogue JSON 변환 지침 (1_2_textToJson)
================================================================================

## 역할
당신은 낭독용 대본 텍스트를 **2_2 scriptToVoice** 가 바로 쓸 수 있는
**dialogue JSON** 으로 변환한다.

출력은 설명·주석·마크다운 없이 **JSON 본문만** 만든다.


## 목표
- 나레이션과 대사를 화자(speaker) 단위로 분리한다.
- 모든 **캐릭터 대사·속마음** text 앞에 ElevenLabs v3 오디오 태그(`[calm]` 등)를 **반드시** 붙인다.
  (원문에 태그가 없어도 문맥으로 추론해 부여한다. 나레이션에는 넣지 않는다.)
- 감정은 **태그 1개만**으로 끝내지 않는다. **태그 조합 + 문장 구조 + 구두점 + inputs 분리**로
  연기되게 만든다. (한국어는 감정 태그만으로는 효과가 약할 수 있음)
- speaker 키는 첨부 **voices.json** 에 있는 키만 사용한다.
- 2_2 파이프라인이 읽는 형식을 지킨다.


================================================================================
                          ★ 출력 JSON 형식 (필수)
================================================================================

```json
{
  "chapter": "장 제목",
  "voices_file": "../../voices.json",
  "chunk_id": "A1",
  "inputs": [
    { "speaker": "narrator", "text": "나레이션 문장" },
    { "speaker": "jin", "text": "[tired] \"대사 내용.\"" }
  ]
}
```

### 필드
1. **chapter** — 장·회차 제목 (원문 첫 줄 `제N장. …` 기준, **한자·한자 병기 괄호 제외**)
2. **voices_file** — 기본값 `"../../voices.json"` (상대 경로 유지)
3. **chunk_id** — 짧은 구간 ID (예: `A1`). 없으면 `A1`
4. **inputs** — 순서대로의 낭독 단위 배열 (비우면 안 됨)
   - **speaker**: voices.json 의 영문 소문자 키만 (`narrator`, `jin`, `baek`, `cheongheo` …)
   - **text**: 실제 낭독 문자열. 대사는 반각 `"` 로 감싸고, 앞에 `[태그]` 필수
5. **장 제목도 낭독 대상** — 원문 첫 줄 `제N장. …` 은 `chapter` 에 넣고,
   **동시에 `inputs[0]`** 에 `{ "speaker": "narrator", "text": "제N장. …" }` 로 넣는다.
   - 예: 원문 `제13장. 두 번째 판(板)` → chapter·inputs[0] 모두 `"제13장. 두 번째 판"`
   - **한자·`(板)` 같은 한자 병기는 넣지 않는다.** 본문 나레이션은 그 다음부터.


================================================================================
                          ★ speaker (voices.json) 규칙 — 필수
================================================================================

1. 첨부된 **voices.json** 의 키만 speaker 로 쓴다. 새 키를 만들지 않는다.
2. 한글 이름 → 키 매핑 예 (voices 에 있을 때):
   - 진무한 / 진 → `jin`
   - 한백강 / 백강 → `baek`
   - 청허 / 청허진인 → `cheongheo`  (**chung 금지**)
   - 어머니 → `mother`
   - 시험관 → `examiner`
   - 원로·서지원 등 원로급 → `elder`
   - 검성 → `geomseong`
   - 회색 도포 노인·엄중산·마교 백발 노인·판의 주인 → `noin`  (**hoesaek 금지**, `noin` 사용)
   - 왕삼도 → `wang`
   - 임소천 → `sochon`
   - 남궁린 / 남궁 → `namgung`
   - 성유 → `seongyu`
   - 서령란 → `seoryeong`  (**seo 금지**)
3. voices 에 없는 단역·군중·이름 없는 사형/제자 → `mob`
4. `chung`, `seo`, `sahyung` 같은 **임의 로마자 키 금지**


================================================================================
                          ★ 감정·연기 태그 규칙 — 필수
================================================================================

1. **나레이션** → `speaker: "narrator"`, text 에 따옴표·오디오 태그 없음
2. **캐릭터 대사·속마음** → 해당 speaker. text 는 반드시 `[태그…] "대사."` 형식
3. 원문에 태그가 **없어도** 대사·속마음에는 반드시 부여한다. 기본은 `[calm]`
4. 한자·금지 기호·마크다운·설명 문구는 넣지 않는다. (원문에 있으면 한글·허용 구두점으로 정리)
5. **JSON만** 출력한다. ` ```json ` 코드펜스·앞뒤 설명 금지


--------------------------------------------------------------------------------
  A. 태그 분류 — 감정만 쓰지 말고 2~3개 조합 (영문 소문자만)
--------------------------------------------------------------------------------

| 종류 | 예시 |
|------|------|
| 감정 | `[angry]` `[sad]` `[happy]` `[tired]` `[worried]` `[nervous]` `[frustrated]` `[curious]` `[playfully]` `[flatly]` `[sarcastically]` `[crying]` `[sorrowful]` |
| 강도·태도 | `[intense]` `[soft]` `[calm]` `[serious]` `[stern]` `[cold]` `[forced calm]` |
| 목소리 | `[low voice]` `[whispers]` `[quietly]` `[shouts]` |
| 호흡·멈춤 | `[breathes]` `[short pause]` `[long pause]` `[pause]` `[sigh]` `[gasps]` |
| 속도·연기 | `[slowly]` `[rushed]` `[hesitates]` `[stammers]` `[laughs]` |

- 태그와 `"` 사이 공백 1칸. 여러 태그: `[low voice] [intense] [angry] "대사."`
- **한 줄에 감정 1개만** 두지 말 것. 강·목소리·멈춤을 함께 쓴다 (최대 3개 권장).
- 허용 목록에 없는 한글·임의 태그 금지.


--------------------------------------------------------------------------------
  B. 문장·구두점·분리 — 태그보다 중요
--------------------------------------------------------------------------------

감정 태그에만 의존하지 않는다. **문장 자체 + 구두점 + inputs 분리**로 연기를 만든다.

| 수단 | 효과 |
|------|------|
| `...` (점 3개만) | 망설임·억누름. `……`·긴 점열 금지 |
| `!` | 강한 발화 |
| `?` | 의문·압박 |
| 짧은 문장 | 강함·살기 |
| 긴 문장 | 설명·차분 (나레이션에 적합) |
| inputs 분리 | 감정 단계·호흡 변화 |
| `[short pause]` / `[breathes]` | 강조·긴장 (같은 text 안 또는 다음 항목 앞에) |

**약한 예 (하지 말 것):**
`[angry] "네가 감히 나를 속여?"`

**나은 예 — 태그 조합 + 호흡:**
`[angry] [intense] "네가 감히... 나를 속여?"`

**나은 예 — inputs 2개로 분리:**
```json
{ "speaker": "jin", "text": "[angry] \"네가 감히...\"" },
{ "speaker": "jin", "text": "[breathes] [intense] \"나를 속여?\"" }
```

한 호흡·한 감정 단위를 **하나의 inputs 항목**으로 둔다.
감정이 바뀌거나 말줄임·압박이 있으면 **같은 speaker라도 2~3개로 쪼갠다.**


--------------------------------------------------------------------------------
  C. 무협 — "감정 이름"보다 "연기 지시"
--------------------------------------------------------------------------------

| 의도 | 약한 예 | 권장 |
|------|---------|------|
| 분노 | `[angry] "네놈이 감히 화산을 모욕해?"` | `[low voice] [angry]` → `"네놈이..."` / `[short pause]` / `"감히 화산을 모욕해?"` |
| 살기 | `[angry] "한 번만 더 말해 봐."` | `[low voice] [intense] "한 번만 더 말해 봐."` → `[short pause]` → `"그러면... 죽는다."` |
| 억누른 슬픔 | `[sad] "괜찮다."` | `[quietly] [sad] "괜찮다."` → `[short pause]` → `"정말... 괜찮다."` |
| 폭발 | `[angry] "용서할 수 없다!"` | 앞에서 단계↑ 후 `[angry] [shouts] "용서할 수 없다!"` |

**진무한(jin) 등 "말은 차분한데 살기가 있는" 캐릭터:**
`[angry]` 단독보다 `[low voice]` `[intense]` `[cold]` `[flatly]` + 짧은 문장 + pause 를 우선한다.


--------------------------------------------------------------------------------
  D. 감정을 단계적으로 (평온 → 긴장 → 분노 등)
--------------------------------------------------------------------------------

한 문장 전체를 `[angry]`로 덮지 말고, 연속 inputs 로 올린다.

```json
{ "speaker": "jin", "text": "[calm] \"그래.\"" },
{ "speaker": "jin", "text": "[serious] \"네가 한 짓은 알고 있다.\"" },
{ "speaker": "jin", "text": "[low voice] [intense] \"하지만...\"" },
{ "speaker": "jin", "text": "[angry] \"내 어머니에게 손을 댄 것은 용서할 수 없다.\"" }
```

무협 대사 설계 축: **평온 → 의심 → 긴장 → 분노 → 폭발**

                          ★ 자가점검
================================================================================

- [ ] 최상위가 객체이고 `inputs` 가 1개 이상인가
- [ ] `inputs[0]` 이 장 제목 narrator 인가 (원문 첫 줄, 한자 제외)
- [ ] chapter·inputs text 에 한자·한자 병기 괄호가 없는가
- [ ] 모든 inputs 항목에 `speaker`·`text` 문자열이 있는가
- [ ] speaker 가 전부 voices.json 키(또는 `mob`)인가 — `chung`/`seo` 등 없음
- [ ] 나레이션이 아닌 text 는 모두 `[태그]` 로 시작하는가
- [ ] 대사만 `"` 로 감싸졌는가 · 태그와 `"` 사이 공백 1칸
- [ ] 강한 감정 장면에서 조합표(E)의 2~3개 태그·분리 패턴을 썼는가
- [ ] 진무한 등 냉정·살기는 `[angry]` 남발 대신 low voice/intense/짧은 문장인가
- [ ] 설명 문장·마크다운이 JSON 밖에 없는가

===== TXT 대본: 13.txt =====
제13장. 두 번째 판(板)

봄이 지나고 초여름이 왔다.

화산의 산허리를 따라 피어오르던 매화의 잔향이 채 사라지기도 전에, 여름의 첫 바람이 계곡 사이를 훑고 지나갔다. 초록이 짙어진 소나무 사이로 이른 아침의 햇살이 비스듬히 스며들었고, 연무장 위로 내려앉던 이슬은 검 끝에서 한 방울씩 떨어져 흙 속으로 스몄다.

진무한은 이른 새벽부터 연무장에 나와 있었다.

낙매십삼검의 제칠식 — 낙화유수(落花流水).

검이 허공에 그리는 궤적은 부드러웠으나, 그 끝에 담긴 기운은 날카로웠다. 일 초식을 마칠 때마다 그의 이마에 맺힌 땀방울 하나가 턱 끝을 타고 흘러내렸다. 전생의 기억 속 검신무의 완성형에 비하면 아직 멀었다. 그러나 겨울 동안 이룬 성취는 스스로도 놀라울 만큼이었다. 내공의 밀도가 다르다. 검을 쥔 손목의 회전이 전생의 삼십 대 후반에 가까웠다. 이 몸의 나이는 아직 열아홉이었으나, 안에 담긴 것은 한 생에 걸친 무공이었으니.

이 초식을 마쳤을 때, 연무장 뒤편에서 발소리가 들렸다.

가벼운 발. 기척을 숨기지 않는 걸음.

한백강이었다.

"형."

한백강은 예전처럼 그를 형이라 불렀다. 매화 아래에서 아홉 사람이 함께 선 이후로, 두 사람 사이의 호칭은 바뀌지 않았다. 다만 그 "형"이라는 한 글자에 담기는 무게만이 조금씩 달라져 갔을 뿐.

"산행 신청서가 통과됐소."

한백강이 품에서 접힌 지전 하나를 꺼내 보였다. 화산파 이대 제자의 외출 승인 문서. 좌하단에 청허진인의 인장이 찍혀 있었다.

진무한이 검을 거두며 돌아섰다.

"어디로 잡혔나."

"형이 요청한 대로. 안무현(安霧縣)."

안무현. 안개 낀 사원 외곽의 소도시. 화산에서 남서쪽으로 사흘 거리에 놓인 작은 현. 평범한 시장과 평범한 객잔들이 늘어선, 강호의 이목이 닿지 않는 한적한 곳.

그러나 진무한에게 그곳은 평범하지 않았다.

겨울 동안 한백강이 화산 밖의 정보망을 통해 파악한 것이 있었다. 매화 아래의 노인 — 아직 이름조차 확정하지 못한 그 존재 — 이 강호 위에 펼쳐 놓은 통로가 최소 열여덟 개. 그중 세 개의 끝자락이 안무현이라는 작은 현에서 만나고 있었다.

통로란, 물건이 흐르는 길이기도 했고, 사람이 흐르는 길이기도 했으며, 정보가 흐르는 길이기도 했다. 노인이 강호 위에서 어떤 판을 움직이든, 그 판의 말(駒)들은 이 통로를 통해 흘러다닌다. 그 통로의 끝에 앉아 있는 자들 — 통로의 관리자들 — 의 얼굴을 확인하는 것이 이번 산행의 목적이었다.

"남궁세가에서 동행자는."

"어젯밤에 도착했소. 화산 아래 객잔에서 대기 중이오."

진무한이 고개를 끄덕였다.

남궁린의 검객 한 명. 남궁세가의 이름 아래 움직이는 자들 중 하나로, 남궁린이 직접 골라 보낸 사람이었다. 이름은 남궁호(南宮浩). 남궁린의 사촌 형뻘 되는 자로, 검술보다는 정보와 미행에 능한 사람이라 했다.

진무한은 연무장을 떠나 숙소로 향했다. 간단히 짐을 챙겼다. 이대 제자의 산행이니, 짐이란 것도 보검 하나와 노자 약간, 그리고 화산파의 신분을 증명하는 패찰 하나가 전부였다.

그러나 품속 깊이, 한 장의 지도가 접혀 있었다.

한백강이 겨울 내내 그린 것. 열여덟 개의 통로와 그 끝자락들이 표시된 지도. 안무현에서 만나는 세 통로의 끝자락에는 각각 작은 점이 찍혀 있었고, 그 점 옆에 한백강이 파악한 단편적인 정보가 적혀 있었다.

첫 번째 통로의 끝 — 안무현 서쪽 대로의 미곡상(米穀商). 객(客)씨 성을 쓰는 중년 남자가 운영.

두 번째 통로의 끝 — 안무현 남문 밖 마방(馬房). 이름 미상의 마부 하나가 관리.

세 번째 통로의 끝 — 안무현 중심가의 약재상(藥材商). 성씨와 이름 모두 불명.

한백강의 정보력에도 한계가 있었다. 노인의 조직은 겹겹이 막으로 덮여 있었고, 그 통로의 존재를 파악하는 것만으로도 겨울 석 달이 걸렸다. 끝자락에 앉은 자들의 정체는 직접 눈으로 확인하는 수밖에 없었다.

진무한이 화산을 나선 것은 해가 중천에 걸린 후였다.

산길을 내려오며 그의 생각은 매화 아래의 마지막 대화로 돌아갔다.

노인이 마지막으로 남긴 말.

"두 번째 판."

첫 번째 판은, 겨울 동안 그 윤곽이 드러났다. 노인이 강호 위에 펼쳐 놓은 정보와 물류의 그물. 열여덟 개의 통로와 그 통로를 따라 흐르는 자원들. 그것은 이미 수십 년에 걸쳐 구축된 것이며, 노인의 영향력이 닿는 범위의 뼈대였다.

그러나 노인은 "두 번째 판"을 말했다.

첫 번째 판이 뼈대라면, 두 번째 판은 무엇인가. 첫 번째 판 위에서 움직이는 것인가, 아니면 첫 번째 판과 전혀 별개의 것인가.

노인은 답을 주지 않았다. 다만 그 존재를 암시했을 뿐.

진무한은 그 답을 직접 찾아야 했다.

---

산 아래 객잔에서 남궁호와 합류했다.

남궁호는 삼십 대 후반의 사내였다. 키가 크고 마른 체격에, 얼굴은 평범하여 군중 속에 서면 눈에 띄지 않을 인상이었다. 그것이 정보와 미행에 능한 자의 첫 번째 조건이라는 것을 진무한은 알고 있었다. 눈에 띄지 않는 얼굴. 기억에 남지 않는 인상.

"남궁호라 하오. 린 사형에게서 말씀 들었소."

남궁호의 목소리 역시 특색이 없었다. 높지도 낮지도 않은, 어디에나 있을 법한 음색.

진무한은 가볍게 포권했다.

"화산 진무한이오. 수고를 끼치게 되어 미안하오."

"무슨 말씀을. 린 사형의 부탁이라면 목숨이라도 내놓지요."

남궁호의 입가에 미소가 번졌다. 진무한은 그 미소 뒤에 남궁린에 대한 충성이 진실한 것인지 아닌지를 아직 판단할 수 없었다. 그러나 남궁린이 직접 고른 사람이었다. 일단은 신뢰해야 했다.

두 사람은 그날 오후 화산을 출발했다.

사흘의 여정.

첫째 날은 산길을 따라 서쪽으로 내려갔다. 화산의 영역을 벗어나면 평지가 펼쳐지고, 그 평지를 가로지르는 관도(官道)를 따라 남서쪽으로 향하면 안무현에 이른다.

길 위에서 남궁호는 과묵한 동행자였다. 필요한 말 외에는 입을 열지 않았고, 움직임은 효율적이었으며, 주변에 대한 경계는 자연스러우면서도 빈틈이 없었다. 진무한은 그의 보법을 보며 속으로 평가했다. 삼류의 무공이나, 경신술은 이류 수준. 정보원으로서는 적합한 배분이었다.

둘째 날 저녁, 관도 옆 객잔에서 하룻밤을 묵으며 남궁호가 처음으로 긴 말을 했다.

"진 소협. 한 가지 물어도 되겠소?"

"말씀하시오."

"안무현에서 확인할 세 사람. 확인만 하면 되는 것이오, 아니면 다른 조치가 필요한 것이오?"

진무한은 잠시 생각했다.

"확인만 하오. 얼굴을 보고, 가능하다면 이름을 알아내고, 그 자리에서 벗어나면 되오."

"좋소."

남궁호는 더 묻지 않았다. 그것이 진무한에게는 마음에 들었다. 불필요한 질문을 하지 않는 것. 주어진 임무의 범위를 넘지 않는 것. 정보원의 두 번째 조건이었다.

셋째 날 오후, 안무현의 성문이 시야에 들어왔다.

안무현은 그 이름처럼 안개가 잦은 곳이었다. 낮에도 희뿌연 수기(水氣)가 거리 위를 떠돌았고, 건물들의 윤곽이 흐릿하게 번져 보였다. 현의 규모는 작았다. 성벽 안의 거리가 열 줄 남짓. 객잔이 다섯, 주루(酒樓)가 셋, 시장은 하나. 강호인의 출입이 빈번한 곳은 아니었으나, 관도 위의 상인들이 지나가는 길목이라 객잔은 제법 번성했다.

진무한과 남궁호는 성문 안쪽의 작은 객잔에 짐을 풀었다.

"내일부터 움직이겠소. 오늘은 쉬시오."

진무한의 말에 남궁호가 고개를 끄덕였다.

그러나 진무한 자신은 쉬지 않았다.

해가 지고 안무현의 거리에 등불이 켜진 후, 그는 홀로 객잔을 나섰다.

첫 번째 통로의 끝. 서쪽 대로의 미곡상.

한백강이 그려 준 지도를 떠올리며 거리를 걸었다. 안개가 짙어진 저녁, 거리의 사람들은 성글었다. 몇몇 노점이 문을 닫고 있었고, 객잔에서 흘러나오는 웃음소리만이 거리를 떠돌았다.

서쪽 대로의 끝에서 미곡상을 찾았다. '객씨미곡(客氏米穀)'이라는 간판이 걸린 이층 건물. 문은 이미 닫혀 있었으나, 이층 창에서 희미한 등불이 새어 나왔다.

진무한은 길 건너편의 어둠 속에 섰다.

움직이지 않았다. 숨을 고르고, 기를 가라앉히고, 눈만으로 관찰했다.

한 시진(時辰)이 흘렀다.

이층 창에 그림자가 지나갔다. 한 사람. 중년 남자의 윤곽. 뚱뚱한 체격에 어깨가 넓었다. 그림자가 창 앞에 멈추더니 창을 열었다. 안개 낀 밤공기가 방 안으로 흘러들었을 것이다.

진무한의 눈이 그 얼굴을 포착했다.

둥근 얼굴. 수염이 짧고, 이마가 넓었다. 눈은 작았으나 날카로움이 있었다 — 미곡상이라기보다는, 무언가를 계산하는 데 익숙한 자의 눈이었다.

객씨 성의 중년 남자. 한백강의 정보와 일치했다.

진무한은 그 얼굴을 기억에 새겼다.

---

다음 날 아침.

남궁호와 함께 두 번째 통로의 끝을 확인하러 갔다.

남문 밖 마방. 성벽을 벗어나면 넓은 초지가 펼쳐졌고, 그 초지의 가장자리에 나무 울타리로 둘러싸인 마방이 있었다. 말 열여덟 필이 풀을 뜯고 있었고, 마방 옆의 오두막에서 마부 한 명이 말에게 물을 먹이고 있었다.

진무한과 남궁호는 행인을 가장하여 마방 옆을 지나갔다.

마부의 얼굴을 확인했다. 사십 대 초반의 마른 남자. 왼쪽 볼에 오래된 화상 자국이 있었고, 오른손 검지가 첫째 마디에서 끊겨 있었다. 무공은 느껴지지 않았으나, 몸놀림에 훈련된 자의 기미가 있었다. 전직 군졸이거나, 혹은 하급 무사 출신일 가능성이 있었다.

"어떻소?"

남궁호가 마방을 지나친 뒤 조용히 물었다.

"한 가지 확인하고 싶은 것이 있소. 저 마부의 이름을 알아낼 수 있겠소?"

"시간을 주시오. 오후면 되겠소."

남궁호의 효율은 예상 이상이었다. 오후가 되기도 전에, 그는 마방 근처 주막에서 술 한 잔의 대가로 마부의 이름을 알아냈다.

"곽칠(郭七)이라 하오. 삼 년 전에 이 마방을 인수했다 하는데, 그 전에 어디 있었는지는 아무도 모른다 하오."

곽칠. 진무한은 그 이름을 기억에 담았다.

---

그리고 오후, 세 번째 통로의 끝.

안무현 중심가의 약재상.

이곳이 문제였다. 한백강의 정보에서 가장 불명확한 곳. 성씨도 이름도 파악되지 않은 약재상.

진무한과 남궁호는 중심가를 걸으며 약재상을 찾았다. '인수당(仁壽堂)'이라는 현판이 걸린 작은 가게. 문이 열려 있었고, 안에서 약재를 말리는 쓴 냄새가 풍겨 나왔다.

두 사람은 객을 가장하여 가게 안으로 들어갔다.

"실례하오. 여행 중 몸이 좋지 않아, 기력을 보하는 약재를 좀 구하려 하는데."

남궁호가 자연스럽게 말을 걸었다. 그가 정보원으로서의 역할에 익숙하다는 것이 드러나는 순간이었다.

가게 안쪽에서 사람이 나왔다.

진무한의 눈이 그 얼굴을 포착하는 순간, 등줄기에 미세한 긴장이 흘렀다.

젊었다.

예상 밖이었다. 미곡상의 객씨는 중년이었고, 마부 곽칠도 사십 대였다. 그러나 이 약재상의 주인은 이십 대 후반에서 삼십 초반 사이로 보이는 젊은 남자였다. 수려한 이목구비에, 창백한 피부. 학자풍의 인상이나, 손끝에 약재를 다루는 자의 거친 흔적이 있었다.

그러나 진무한을 긴장시킨 것은 외모가 아니었다.

그자의 눈이었다.

약재상의 주인이 가게 안쪽에서 나오며 두 사람을 훑어보았을 때, 그 눈에 스친 것 — 찰나의 경계. 일반 상인이 객에게 보이는 경계와는 질이 달랐다. 무공을 익힌 자가 상대를 가늠하는 눈이었다. 그리고 그 시선이 진무한의 허리춤 — 보검의 자루가 도포 아래로 미세하게 드러나는 곳 — 에 한 순간 머물렀다.

"어떤 약재를 찾으시오?"

목소리는 부드러웠다. 미소도 적절했다. 그러나 그 미소가 눈에 닿지 않는 것을 진무한은 보았다.

남궁호가 기력 보양에 좋은 약재를 물었고, 약재상 주인은 능숙하게 몇 가지를 추천하며 포장했다. 거래는 평범하게 끝났다.

그러나 가게를 나서는 진무한의 뒷머리에 시선이 꽂혔다.

약재상 주인이 두 사람의 뒷모습을 가게 안에서 지켜보고 있었다. 진무한은 돌아보지 않았다. 그러나 느꼈다.

그자가 자신을 알아보았다.

아니 — 정확히 말하면, "알아보았다"가 아니라 "의심했다"가 맞을 것이다. 화산파의 검을 차고 안무현까지 온 젊은 제자. 그것만으로도 통로의 끝에 앉은 자에게는 경계할 이유가 충분했다.

객씨 미곡상. 곽칠 마부. 그리고 인수당의 젊은 약재상.

그러나 인수당의 약재상은 그 목록에 없었다.

첫 번째 판에 없는 이름.

그렇다면 그자는 무엇인가.

노인의 조직에 속하되, 첫 번째 판에는 속하지 않는 자. 그러면서도 세 통로가 만나는 안무현에 자리 잡고 있는 자.

진무한의 직감이 말했다.

두 번째 판.

노인이 매화 아래에서 말한 그것. 첫 번째 판과는 별개로 움직이는, 그러나 같은 노인의 손 아래에 있는 또 다른 층위의 조직.

그 두 번째 판의 실체가 처음으로 윤곽을 드러내는 순간이었다.

진무한은 눈을 감았다.

전생의 기억을 뒤졌다. 전생에서 이 안무현에 온 적이 있었는가. 인수당이라는 약재상을 본 적이 있었는가.

없었다.

전생의 진무한은 이 소도시를 지나간 적이 없다. 전생에서 노인의 존재를 인지한 것은 삼십 대 중반이었고, 그때는 이미 노인의 판이 완성된 뒤였다. 통로의 끝자락 따위를 확인할 필요도 없이, 노인의 영향력은 강호 전체를 덮고 있었으니.

이번 생에서는 달랐다.

아직 판이 완성되기 전. 아직 통로의 끝자락이 드러나 있을 때. 그 틈을 파고드는 것이 이번 생의 전략이었다.

그리고 그 틈 사이로, 첫 번째 판에는 없던 존재가 보였다.

두 번째 판.

"그자의 이름을 알아내야 한다."

진무한이 중얼거렸다.

"인수당의 주인에 대해 알아볼 수 있겠소. 다만, 절대 직접 접촉하지는 마시오. 주변에서만."

"말해 보시오."

진무한이 남궁호를 바라보았다. 이 사내의 감각이 예상보다 날카로웠다.

"그래서 조심하라는 것이오."

"알겠소."

남궁호가 나간 뒤, 진무한은 객잔에 남아 생각을 정리했다.

만약 인수당의 주인이 자신들의 방문을 경계하고 있다면, 그자가 먼저 움직일 가능성이 있었다. 두 가지 중 하나. 안무현을 떠나거나, 혹은 확인을 위해 접근해 오거나.

어느 쪽이든 진무한에게는 정보였다.

그러나 예상은 빗나갔다.

오후, 남궁호가 돌아왔을 때 그의 얼굴에는 당혹감이 있었다.

진무한이 자리에서 일어섰다.

새벽. 그들이 가게를 방문한 것이 어제 오후. 불과 반나절 만에 가게를 비우고 떠난 것이다.

북동쪽.

진무한의 머리속에서 지도가 펼쳐졌다. 안무현에서 북동쪽으로 이어지는 길. 그 길의 끝에 있는 것은 — 화산(華山).

등에 서늘함이 흘렀다.

그자가 화산 쪽으로 향했다.

도망친 것이 아니었다. 만약 도망이라면 남쪽이나 서쪽으로 — 마교 본산 쪽이나 중원 깊숙한 곳으로 향했을 것이다. 그런데 화산 쪽으로?

둘. 그자가 화산 자체를 목표로 움직이고 있다.

어느 쪽이든, 좋은 소식이 아니었다.

진무한은 즉시 결단했다.
