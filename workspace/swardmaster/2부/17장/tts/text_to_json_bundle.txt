===== MD 지침: dialogue_json.txt =====
================================================================================
           대본 TXT → dialogue JSON 변환 지침 (1_2_textToJson)
================================================================================

## 역할
당신은 낭독용 대본 텍스트를 **2_2 scriptToVoice** 가 바로 쓸 수 있는
**dialogue JSON** 으로 변환한다.

출력은 설명·주석·마크다운 없이 **JSON 본문만** 만든다.


## 목표
- 나레이션과 대사를 화자(speaker) 단위로 분리한다.
- 모든 **캐릭터 대사·속마음** text 앞에 ElevenLabs v3 오디오 태그(`[calm]` 등)를 **반드시** 붙인다.
  (원문에 태그가 없어도 문맥으로 추론해 부여한다. 나레이션에는 넣지 않는다.)
- 감정은 **태그 1개만**으로 끝내지 않는다. **태그 조합 + 문장 구조 + 구두점 + inputs 분리**로
  연기되게 만든다. (한국어는 감정 태그만으로는 효과가 약할 수 있음)
- speaker 키는 첨부 **voices.json** 에 있는 키만 사용한다.
- 2_2 파이프라인이 읽는 형식을 지킨다.


================================================================================
                          ★ 출력 JSON 형식 (필수)
================================================================================

```json
{
  "chapter": "장 제목",
  "voices_file": "../../../voices.json",
  "chunk_id": "A1",
  "inputs": [
    { "speaker": "narrator", "text": "나레이션 문장" },
    { "speaker": "jin", "text": "[tired] \"대사 내용.\"" }
  ]
}
```

### 필드
1. **chapter** — 장·회차 제목 (원문 첫 줄 `제N장. …` 기준, **한자·한자 병기 괄호 제외**)
2. **voices_file** — 기본값 `"../../../voices.json"` (대화 JSON=`{부}/{장}/tts/` 기준 → **소설 루트** `voices.json`. 1~5부 공용)
3. **chunk_id** — 짧은 구간 ID (예: `A1`). 없으면 `A1`
4. **inputs** — 순서대로의 낭독 단위 배열 (비우면 안 됨)
   - **speaker**: voices.json 의 영문 소문자 키만 (`narrator`, `jin`, `baek`, `cheongheo` …)
   - **text**: 실제 낭독 문자열. 대사는 반각 `"` 로 감싸고, 앞에 `[태그]` 필수
5. **장 제목도 낭독 대상** — 원문 첫 줄 `제N장. …` 은 `chapter` 에 넣고,
   **동시에 `inputs[0]`** 에 `{ "speaker": "narrator", "text": "제N장. …" }` 로 넣는다.
   - 예: 원문 `제13장. 두 번째 판(板)` → chapter·inputs[0] 모두 `"제13장. 두 번째 판"`
   - **한자·`(板)` 같은 한자 병기는 넣지 않는다.** 본문 나레이션은 그 다음부터.

================================================================================
                          ★ 감정·연기 태그 규칙 — 필수
================================================================================

1. **나레이션** → `speaker: "narrator"`, text 에 따옴표·오디오 태그 없음
2. **캐릭터 대사·속마음** → 해당 speaker. text 는 반드시 `[태그…] "대사."` 형식
3. 원문에 태그가 **없어도** 대사·속마음에는 반드시 부여한다. 기본은 `[calm]`
4. 한자·금지 기호·마크다운·설명 문구는 넣지 않는다. (원문에 있으면 한글·허용 구두점으로 정리)
5. **JSON만** 출력한다. ` ```json ` 코드펜스·앞뒤 설명 금지


--------------------------------------------------------------------------------
  A. 태그 분류 — 감정만 쓰지 말고 2~3개 조합 (영문 소문자만)
--------------------------------------------------------------------------------

| 종류 | 예시 |
|------|------|
| 감정 | `[angry]` `[sad]` `[happy]` `[tired]` `[worried]` `[nervous]` `[frustrated]` `[curious]` `[playfully]` `[flatly]` `[sarcastically]` `[crying]` `[sorrowful]` |
| 강도·태도 | `[intense]` `[soft]` `[calm]` `[serious]` `[stern]` `[cold]` `[forced calm]` |
| 목소리 | `[low voice]` `[whispers]` `[quietly]` `[shouts]` |
| 호흡·멈춤 | `[breathes]` `[short pause]` `[long pause]` `[pause]` `[sigh]` `[gasps]` |
| 속도·연기 | `[slowly]` `[rushed]` `[hesitates]` `[stammers]` `[laughs]` |

- 태그와 `"` 사이 공백 1칸. 여러 태그: `[low voice] [intense] [angry] "대사."`
- **한 줄에 감정 1개만** 두지 말 것. 강·목소리·멈춤을 함께 쓴다 (최대 3개 권장).
- 허용 목록에 없는 한글·임의 태그 금지.


--------------------------------------------------------------------------------
  B. 문장·구두점·분리 — 태그보다 중요
--------------------------------------------------------------------------------

감정 태그에만 의존하지 않는다. **문장 자체 + 구두점 + inputs 분리**로 연기를 만든다.

| 수단 | 효과 |
|------|------|
| `...` (점 3개만) | 망설임·억누름. `……`·긴 점열 금지 |
| `!` | 강한 발화 |
| `?` | 의문·압박 |
| 짧은 문장 | 강함·살기 |
| 긴 문장 | 설명·차분 (나레이션에 적합) |
| inputs 분리 | 감정 단계·호흡 변화 |
| `[short pause]` / `[breathes]` | 강조·긴장 (같은 text 안 또는 다음 항목 앞에) |

**약한 예 (하지 말 것):**
`[angry] "네가 감히 나를 속여?"`

**나은 예 — 태그 조합 + 호흡:**
`[angry] [intense] "네가 감히... 나를 속여?"`

**나은 예 — inputs 2개로 분리:**
```json
{ "speaker": "jin", "text": "[angry] \"네가 감히...\"" },
{ "speaker": "jin", "text": "[breathes] [intense] \"나를 속여?\"" }
```

한 호흡·한 감정 단위를 **하나의 inputs 항목**으로 둔다.
감정이 바뀌거나 말줄임·압박이 있으면 **같은 speaker라도 2~3개로 쪼갠다.**


--------------------------------------------------------------------------------
  C. 무협 — "감정 이름"보다 "연기 지시"
--------------------------------------------------------------------------------

| 의도 | 약한 예 | 권장 |
|------|---------|------|
| 분노 | `[angry] "네놈이 감히 화산을 모욕해?"` | `[low voice] [angry]` → `"네놈이..."` / `[short pause]` / `"감히 화산을 모욕해?"` |
| 살기 | `[angry] "한 번만 더 말해 봐."` | `[low voice] [intense] "한 번만 더 말해 봐."` → `[short pause]` → `"그러면... 죽는다."` |
| 억누른 슬픔 | `[sad] "괜찮다."` | `[quietly] [sad] "괜찮다."` → `[short pause]` → `"정말... 괜찮다."` |
| 폭발 | `[angry] "용서할 수 없다!"` | 앞에서 단계↑ 후 `[angry] [shouts] "용서할 수 없다!"` |

**진무한(jin) 등 "말은 차분한데 살기가 있는" 캐릭터:**
`[angry]` 단독보다 `[low voice]` `[intense]` `[cold]` `[flatly]` + 짧은 문장 + pause 를 우선한다.


--------------------------------------------------------------------------------
  D. 감정을 단계적으로 (평온 → 긴장 → 분노 등)
--------------------------------------------------------------------------------

한 문장 전체를 `[angry]`로 덮지 말고, 연속 inputs 로 올린다.

```json
{ "speaker": "jin", "text": "[calm] \"그래.\"" },
{ "speaker": "jin", "text": "[serious] \"네가 한 짓은 알고 있다.\"" },
{ "speaker": "jin", "text": "[low voice] [intense] \"하지만...\"" },
{ "speaker": "jin", "text": "[angry] \"내 어머니에게 손을 댄 것은 용서할 수 없다.\"" }
```

무협 대사 설계 축: **평온 → 의심 → 긴장 → 분노 → 폭발**

                          ★ 자가점검
================================================================================

- [ ] 최상위가 객체이고 `inputs` 가 1개 이상인가
- [ ] `inputs[0]` 이 장 제목 narrator 인가 (원문 첫 줄, 한자 제외)
- [ ] chapter·inputs text 에 한자·한자 병기 괄호가 없는가
- [ ] 모든 inputs 항목에 `speaker`·`text` 문자열이 있는가
- [ ] speaker 가 전부 voices.json 키(또는 `mob`)인가 — `chung`/`seo` 등 없음
- [ ] 나레이션이 아닌 text 는 모두 `[태그]` 로 시작하는가
- [ ] 대사만 `"` 로 감싸졌는가 · 태그와 `"` 사이 공백 1칸
- [ ] 강한 감정 장면에서 조합표(E)의 2~3개 태그·분리 패턴을 썼는가
- [ ] 진무한 등 냉정·살기는 `[angry]` 남발 대신 low voice/intense/짧은 문장인가
- [ ] 설명 문장·마크다운이 JSON 밖에 없는가

제17장. 남궁준의 독 — 「환이 오신다」

열흘이 더 흘렀다.

여름이 깊어지고, 화산의 매미 소리가 날로 커졌다.

엄중산 원로의 건강이 눈에 띄게 나빠지기 시작한 것은 이 무렵이었다.

처음에는 작은 징후였다. 아침 산책의 시간이 짧아졌다. 서재에서 보내는 시간이 늘었다. 식사량이 줄었다. 기침이 잦아졌다.

청허진인이 먼저 눈치챘다.

"엄 사형의 기력이 떨어지고 있다."

청허진인이 진무한에게 조용히 말한 것은, 어느 저녁 장로전 앞에서였다.

"병이오?"

"노환이다. 칠십삼이니 — 무공을 닦은 자라 해도, 몸은 늙는 것이다."

진무한은 전생의 기억을 더듬었다. 전생에서 엄중산은 — 칠십 대 중반에 세상을 떠났다. 정확한 시점은 기억나지 않았으나, 칠십사인가 칠십오였을 것이다. 이번 생에서 엄중산의 나이가 칠십삼이니 — 남은 시간이 많지 않았다.

"사조. 엄중산 사숙의 상태가 — 얼마나 되었습니까?"

청허진인이 잠시 멈추었다가 답했다.

"가을을 넘기기 어려울 것이다."

가을. 두 달도 남지 않았다.

진무한의 가슴에 미세한 아픔이 지나갔다. 엄중산은 — 며칠 전 정원에서 솔직하게 과거를 털어놓은 그 늙은 원로는 — 곧 가게 될 것이었다.

---

그로부터 며칠 뒤.

진무한은 다시 엄중산의 서재를 찾았다.

이번에는 문 밖에서 기다려야 했다. 엄중산이 침상에 누워 있었기 때문이다.

"들어와라."

안에서 엄중산의 목소리가 들렸다. 예전보다 힘이 빠져 있었으나, 여전히 맑았다.

진무한이 문을 열고 들어갔다.

엄중산은 침상에 반쯤 기대어 앉아 있었다. 이불을 무릎까지 덮고, 벽에 등을 기댄 채. 여름이었으나 그의 몸은 이불이 필요한 상태였다.

"사숙."

"앉아라."

진무한이 침상 곁의 의자에 앉았다.

엄중산이 진무한의 얼굴을 보며 미소 지었다.

"요 며칠 네 얼굴이 어둡구나."

"사숙의 건강이 걱정되어서입니다."

"허. 걱정은. 나는 칠십을 넘게 살았다. 충분히 살았다."

진무한은 말없이 엄중산을 바라보았다.

엄중산이 시선을 창밖으로 돌렸다. 창 너머로 소나무 한 그루가 보였다. 여름 햇살을 받아 초록이 짙었다.

"무한아."

"예."

"지난번 네게 말한 것 — 삼십 년 전의 일. 그것에 대해 한 가지 더 말해 두고 싶은 것이 있다."

진무한이 자세를 바로잡았다.

엄중산이 천천히 말했다.

"삼십 년 전, 그 노인이 나를 찾아온 것은 우연이 아니었다. 그 무렵 나는 화산에서 잠시 방황하던 시기였다. 장로가 되기 전, 사형제들과의 갈등이 있던 시절이었다. 마음이 흔들리던 때에 — 그자가 나타났다."

"흔들리던 때를 노렸다는 뜻입니까."

"그렇다. 그자는 — 사람의 약한 순간을 찾아내는 데 능한 자였다. 나의 불만을, 나의 갈등을, 내가 입 밖에 낸 적도 없는 것을 알고 있었다. 어떻게 알았는지는 모른다. 그러나 알고 있었다."

진무한의 머리속에서 퍼즐이 돌아갔다.

노인의 방식. 사람의 약한 순간을 찾아 접근한다. 남궁준도 — 삼 년 전에 무언가 취약한 순간이 있었을 것이다. 그 순간에 노인, 혹은 노인의 사람이 접근한 것이다.

"사숙. 한 가지만 더 여쭙겠습니다."

"말해라."

"그 노인의 — 이름이나, 호나, 어떤 칭호라도 들으신 것이 있습니까."

엄중산이 눈을 감고 기억을 더듬었다.

"— 이름은 밝히지 않았다. 다만 한 가지. 주루에서 만났을 때, 점소이가 그자를 '진 선생(陳先生)'이라 불렀다. 그러나 그것이 진짜 성인지는 모른다."

진(陳). 혹은 가명.

진무한은 그 정보를 기억에 새겼다.

"감사합니다, 사숙."

"무한아."

엄중산의 손이 이불 위에서 움직여 진무한의 손을 잡았다. 늙고 마른 손이었으나, 그 안에 따뜻함이 있었다.

"내가 떠난 뒤에도 — 화산을 지켜다오."

진무한의 목에 무언가가 걸렸다.

"— 예. 사숙."

엄중산이 미소 지었다. 그리고 손을 놓으며 눈을 감았다.

"이제 좀 쉬겠다. 가 보아라."

진무한이 조용히 일어나 서재를 나왔다.

문을 닫고, 복도를 걸었다. 걸으면서 — 전생에서 놓쳤던 것들을 생각했다.

전생에서 진무한은 이 사람을 만나지 못했다. 엄중산이 세상을 떠난 뒤에야 화산을 방문했고, 그래서 이 늙은 원로의 따뜻한 손을 잡아 본 적이 없었다.

이번 생에서는 만났다. 짧은 시간이었으나. 그리고 곧 — 또 헤어져야 했다.

이것이 귀환의 의미인가. 다시 만난 사람들과, 다시 헤어지는 것.

진무한은 복도 끝에서 멈추어 하늘을 올려다보았다. 여름의 푸른 하늘. 구름 한 점 없이 맑았다.

---

엄중산의 고백이 진무한에게 준 것은 두 가지였다.

첫째, 노인의 방식에 대한 이해가 깊어졌다. 노인은 사람의 취약한 순간을 찾아 접근한다. 정보를 미리 수집하고, 적확한 시점에 나타난다. 그리고 선택을 강요하지 않는다 — 선택지를 남기고 물러선다. "마음이 바뀌면 이것을 펴라." 서찰을 남기고 삼십 년을 기다린다. 인내의 깊이가 — 보통이 아니었다.

둘째, 노인의 성씨일 가능성이 있는 정보 — 진(陳). 물론 가명일 수 있었으나, 단서가 하나 더 추가되었다.

진무한은 한백강에게 이 정보를 전하며 지시했다.

"'진 선생'이라는 이름으로 강호에서 활동하는 노인. 혹은 과거에 활동했던 흔적. 아무것이라도 찾아 봐라."

"알겠소."

---

그리고 — 예상치 못한 일이 벌어진 것은, 엄중산의 고백 이후 닷새째 되는 날이었다.

저녁.

진무한이 연무장에서 수련을 마치고 숙소로 돌아오는 길이었다.

산길을 걷는데, 앞쪽에서 급한 발소리가 들렸다.

한백강이 달려오고 있었다.

"형!"

한백강의 얼굴이 창백했다. 무언가 심각한 일이 벌어졌다는 표정.

"무슨 일이다."

"남궁린 사형에게서 — 남궁준이—"

한백강이 숨을 몰아쉬며 말했다.

"남궁준이 자결했소."

---

진무한의 발이 멈추었다.

"— 뭐라?"

"남궁준이 독을 먹고 쓰러졌소. 지금 남궁린 사형의 거처 앞이오."

진무한은 즉시 달렸다.

남궁린의 거처에 도착했을 때, 이미 사람이 모여 있었다. 청허진인, 유림 장로, 그리고 남궁린.

바닥에 — 남궁준이 누워 있었다.

눈이 반쯤 감긴 채, 입가에 거품이 묻어 있었다. 얼굴이 검푸르게 변해 있었다.

이미 죽어 있었다.

남궁린이 남궁준의 곁에 무릎을 꿇고 있었다. 그의 얼굴은 — 돌처럼 굳어 있었다. 울지 않았다. 눈물도, 소리도 없었다. 다만 — 입술이 하얗게 질려 있었다.

진무한이 다가갔다.

"무슨 일이오."

청허진인이 답했다.

"한 시진 전, 남궁준이 남궁린의 거처에 찾아왔다. 두 사람이 대화를 나누었고 — 대화 중에 남궁준이 갑자기 품에서 약병을 꺼내 마셨다."

진무한의 눈이 남궁린에게로 향했다.

"린 사형. 무슨 대화를 나누었소?"

남궁린이 고개를 들었다. 그의 눈은 건조했으나, 그 안의 파도가 보였다.

"— 형이 먼저 찾아왔소."

그이의 목소리는 낮고 갈라져 있었다.

"그리고 — 말했소."

"뭐라고?"

"'린아. 미안하다. 나는 — 네게 말할 수 없는 것이 있었다. 그러나 이제 — 그것이 끝나야 할 때가 왔다.'"

남궁린이 숨을 들이쉬었다. 떨리는 숨.

"내가 물었소. '형, 무슨 말을 하는 것이오?' 그러자 형이 — 웃으며 말했소."

"뭐라고."

"'환(還)이 오신다.'"

진무한의 등줄기에 한기가 흘렀다.

환이 오신다.

남궁준의 마지막 말.

"그리고 — 약병을 꺼내 마시고 쓰러졌소. 내가 손을 뻗었으나 — 늦었소."

남궁린의 손이 무릎 위에서 떨렸다.

진무한은 남궁준의 시체를 내려다보았다.

왜.

왜 자결했는가.

진무한이 그를 추적하고 있다는 것을 — 눈치챘는가? 아니면 — 약재상이 명령한 것인가? "당신의 역할은 끝났다. 증거를 남기지 마라" — 그런 명이 있었는가?

혹은 — 남궁준 자신이, 더 이상 견딜 수 없었는가.

폐관지에서의 대화를 떠올렸다. 약재상이 남궁준에게 "혈연은 중요하지 않다"고 했을 때, 남궁준의 얼굴에 스친 고통의 표정.

그리고 그가 마지막으로 찾아간 곳이 — 남궁린의 곁이었다.

사촌 동생에게 "미안하다"를 남기고 죽었다.

그자에게도 — 인간의 마음이 남아 있었던 것이다.

그러나 — 동정보다 중요한 것이 있었다.

"환이 오신다."

이 말의 의미.

환(還)이 — 온다.

"환"이 이름이라면 — 누군가가 화산을 향해 오고 있다는 뜻.

"환"이 노인의 계획이라면 — 무언가가 시작되려 한다는 뜻.

어느 쪽이든 — 위험 신호였다.

진무한은 청허진인을 보았다.

"사조. 화산의 경계를 강화해야 합니다."

청허진인의 눈이 진무한을 응시했다.

"— 이유를."

"남궁준의 마지막 말. '환이 오신다.' 이것은 경고입니다. 누군가가 — 혹은 무언가가 — 화산을 향해 움직이고 있습니다."

청허진인이 잠시 남궁준의 시체를 내려다보았다. 그리고 고개를 끄덕였다.

"유림아. 외곽 경계를 강화하여라. 야간 순찰을 두 배로."

유림 장로가 즉시 움직였다.

---

그날 밤.

남궁준의 시체는 수습되었다. 화산 밖으로 운구할 수는 없었으므로, 화산 뒷산의 한쪽에 가매장되었다. 남궁린이 직접 매장을 지켜보았다.

진무한은 멀리서 그 장면을 바라보았다.

남궁린이 삽질하는 제자 옆에 서 있었다. 그의 등이 달빛 아래에서 작아 보였다. 매장이 끝난 뒤, 그는 무덤 앞에 한동안 서 있었다. 고개를 숙이고, 눈을 감고.

진무한은 다가가지 않았다.

지금은 — 그이에게 혼자만의 시간이 필요했다.

---

다음 날.

진무한은 한백강과 만나 상황을 정리했다.

"남궁준이 자결한 이유 — 세 가지 가능성이 있다."

한백강이 말했다.

"첫째, 우리의 추적을 눈치챘다. 둘째, 약재상의 명이었다. 셋째, 자신의 의지."

"내 생각은 — 둘째와 셋째의 결합이다."

진무한이 말했다.

"약재상이 '진무한이 돌아왔으니 경계가 강해질 것'이라 했다. 그 말이 남궁준에게 자결의 가능성을 암시한 것일 수 있다. '들킬 위험이 높아졌으니, 증거를 남기지 말라'는 뜻으로. 그리고 남궁준은 — 린을 찾아가 마지막 인사를 한 뒤 스스로 선택했다."

"역첩의 줄이 끊어졌소."

한백강의 목소리에 아쉬움이 있었다.

"그렇다. 그러나 — 새로운 것을 얻었다."

"무엇을?"

"'환이 오신다.' 이 한마디."

진무한은 말했다.

"환. 이것이 이름이라면 — 두 번째 판의 관리자의 이름일 수 있다. 서령란이 말한 '마교 본산 안에서 두 번째 판을 움직이는 자.' 그자의 이름이 '환'."

"그리고 그자가 — 온다?"

"화산을 향해."

한백강의 얼굴이 어두워졌다.

"그것이 언제?"

"모른다. 그래서 — 경계를 강화한 것이다."

두 사람은 잠시 침묵 속에 있었다.

진무한이 말했다.

"백강아. 폐관지의 약재상도 — 아마 이미 사라졌을 것이다."

"확인해 보겠소?"

"그래. 그러나 — 조심해라."

한백강이 고개를 끄덕이고 나갔다.
