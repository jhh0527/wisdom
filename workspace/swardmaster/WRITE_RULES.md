# 검신귀환록 — 젠스파크 작성 규칙

젠스파크 **한 채팅 = 한 장**. 이 파일 + 해당 `briefs/CHAPTER_NN.md` + 직전 장 끝부분만 넣는다.  
부 전체 줄거리·앞장 전문은 넣지 않는다.  
필요 시 해당 장 ~700자만 BRIEF 비트로 옮긴다.

## 합본 전 (필수)

BRIEF에 아래가 **실제 문장으로** 채워져 있어야 한다.  
`(직전 장 말 상태)` · `(한 문장 — …)` · `(이 장 등장만)` 등 **자리표시·공란이 있으면 합본·생성하지 말 것.**

1. 직전 장에서 이어질 상태 (누가 어디 · 미결)  
2. 비트 8~12 (장면 단위 · 순서 고정)  
3. 종료 훅 한 줄  
4. 직전 장 끝 **800~1,500자** (첨부)  
5. 등장 호칭·관계 2~6줄 (characters.md 전문 금지)  
6. 숫자·고유명사 손채움 (자동 추측 목록 금지)  
7. 정보 격리 한 줄 이상 (누가 무엇을 모름)  
8. 장소: 시작 → 끝 · 이동 여유  
9. 이 장 사건 ID만 (`chapter_map` · 다음 장 ID 금지)  
10. 이번에 심거나 만질 복선 Fxx만  

양식: `briefs/_TEMPLATE.md`

## 분량

- 목표: 본문 **9,000~11,000자** (제목·주석·메타 제외)
- 부족해도 **신규 사건·신규 주요 인물·새 조직·사망·자결·납치**로 채우지 말 것
- 밀도만 높일 것: 감각, 내면, 대화 호흡, BRIEF에 적힌 이동·관찰·전투 규모

## 반드시 따를 것

1. `briefs/CHAPTER_NN.md`의 **비트 번호 순서**대로만 진행
2. 등장 인물·호칭·관계는 BRIEF·인물 발췌만 사용 (예: 남궁준=**사촌 형뻘**, 삼촌 금지)
3. 인원·사상 숫자는 BRIEF에 적힌 값 고정
4. 시점 나이·계절·장소(시작→끝)를 BRIEF 상단에 맞출 것
5. **정보 격리**: BRIEF에 「모름」인 사실을 대사·독백에 넣지 말 것
6. 다음 장 사건 선취 금지. 종료 훅은 BRIEF에 적힌 한 줄만

## 쓰기 전 승인 (있으면 채팅 중단·사람 확인)

- 새 이름 있는 인물 / 새 문파·당·루
- 대규모 전투, 배신 확정, 사망·자결·납치
- 기존 사건 결과·시간 순서 변경
- `events.md`에 없는 사건 ID

→ 승인 후 `events.md`에 ID 추가한 다음에만 본문 작성.

## 문체

- 한국어 문어체 무협. 한자 병기 가능: `진무한(陳武寒)`
- 유튜브 낭독: 짧은 문장과 긴 문장 혼용. 대사·액션은 끊어서
- 상태창·설정 덤프·설명조 나열 금지
- 상세 세계관은 `CURSOR_RULES.md` / `world.md` 등과 충돌 시 BRIEF·events 우선(본문 확정분)

## 출력

- 장 제목 한 줄 후 본문만
- 메타 코멘트·「이어서」·비트 번호 표기 넣지 말 것
- 본문 전체를 아래 구분자로 감싼다 (구분자 밖 텍스트 금지):

```
<<<CHAPTER_START>>>
(제목 한 줄)
(본문)
<<<CHAPTER_END>>>
```

- 끝나면 스스로: 비트 누락 / 신규 사건 / 글자 수 점검 후 부족·초과만 수정

## 생성 직후 (사람 또는 Agent 1회 · BRIEF에 넣지 말 것)

이음 3줄만:

1. 직전 장 끝 ↔ 이 장 첫 장면이 같은 상태인가  
2. 미결 사건이 이어지는가  
3. 종료 훅이 다음 장 입구인가  

필요 시 설정만: 호칭·생존·납치·나이·계절 (`REVIEW_PROMPT` 1~3차 해당분만).

## 첨부 순서 (권장)

1. 이 파일 (`WRITE_RULES.md`)
2. `briefs/CHAPTER_NN.md` (공란 없이)
3. 필요 인물만 발췌 (짧게 · BRIEF 등장과 중복이면 생략 가능)
4. 직전 장 **끝 800~1,500자**
