# BRIEF 템플릿 — CHAPTER_NN

젠스파크에 넣기 전, 이 양식을 채워 `briefs/CHAPTER_NN.md`로 저장한다.  
사건 ID는 `events.md` / `chapter_map.md`에서 복사.  
**공란·`(…)` 자리표시가 남아 있으면 합본·생성하지 않는다.**

```text

- 나이:
- 계절:
- 장소: (시작 → 끝 · 이동 여유 한 줄. 예: 화산 거처 → 서쪽 계곡 · 당일 저녁)

이 장 사건 ID (이것만 처리 · 다음 장 ID 금지):
- E…

- 새 조직 / 새 주요 인물 / 사망·자결·납치 (BRIEF에 없으면)
```

## 채운 뒤 확인 (네 항목 + 고정)

1. 직전 장 말 상태  
2. 비트 8~12 (장면 단위)  
3. 종료 훅 한 줄  
4. 직전 장 꼬리 800~1,500자 (합본 시 첨부)  
5. 등장 호칭·관계 / 숫자·고유명사 / 정보 격리 / 장소·이동 / 이 장 사건 ID만 / 복선  

부 전체 줄거리는 BRIEF·젠스파크에 넣지 않는다. 필요 시 해당 장 ~700자만 비트로 옮긴다.
