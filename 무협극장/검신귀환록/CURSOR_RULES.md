# 검신귀환록 — 작품 규칙 (CURSOR_RULES)

유튜브 3시간 분량 무협 소설 제작용. AI는 새 장 작성·수정 시 이 규칙을 따른다.

## 필수 참조 파일

작업 전 반드시 읽기:

1. `events.md` (사건 순서·확정 상태)
2. `chapter_map.md` (해당 장의 사건 ID·제목)
3. `world.md`
4. `characters.md`
5. `martial_arts.md`
6. `timeline.md`
7. `relationships.md` (정보 격리)
8. `foreshadowing.md` (새 복선·회수 시 갱신)

젠스파크로 쓸 때는 `WRITE_RULES.md` + `briefs/CHAPTER_NN.md`가 주입력이다. 부 전체 줄거리 전문은 넣지 않는다.

## 문체

- 한국어 문어체 무협. 한자 병기 가능: `진무한(陳武寒)`.
- 감각·내면 독백 비중을 유지. 설명 덤프·상태창 남발 금지.
- 장면당 하나의 감정 중심. 과한 요약 나열 지양.
- 유튜브 낭독 호흡: 짧은 문장과 긴 문장을 섞되, 대사·액션은 끊어서.

## 금지

- 사망 인물 설명 없이 재등장
- 모르는 인물이 판·회귀·천마의 눈 내부 정보를 아는 척
- 경지·나이·계절·장소가 바이블과 충돌하는 즉흥 설정
- 남궁린을 갑자기 수다쟁이로 만들기
- 현생 소년 진무한에게 전생 현경급 「검 없이 벤다」를 남발
- 복선을 심고 `foreshadowing.md`에 안 적기

## 새 장 작성 체크

1. 시점 나이·계절을 `timeline.md`에 맞춰 표기 (**1부·2부 나이 충돌 시 BRIEF에 선택한 기준을 명시**)
2. 이 장 사건 ID가 `events.md`에 있는지 확인. 없으면 승인 후 추가
3. 등장 인물 상태(생존/사망/납치/정보) 확인
4. 무공·경지가 `martial_arts.md`와 맞는지 확인
5. 장소 이동에 충분한 시간 배분
6. 새/회수 복선은 `foreshadowing.md` 갱신
7. 충돌이 보이면 본문을 고치거나 `review.md`에 기록
8. 젠스파크 사용 시: 신규 사건으로 분량 채우지 말 것 (`WRITE_RULES.md`)

## 추상 품질 (별도 리뷰)

감동·긴장·빌드업·악역 매력은 자동 검수로 부족하다.  
필요 시 `REVIEW_PROMPT.md`의 「문예 리뷰」 섹션을 따로 돌린다.
