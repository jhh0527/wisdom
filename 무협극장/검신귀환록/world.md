# 검신귀환록 — 세계관

> 본 파일은 설정 바이블이다. 장 작성·수정 시 반드시 참조하고, 충돌이 생기면 `review.md`에 기록한다.

## 기본 설정

- **장르**: 중세 강호 회귀 무협
- **제목**: 검신귀환록(劍神歸還錄)
- **핵심 전제**: 천하제일검 진무한이 **35세**에 사제 한백강에게 죽은 뒤, 「역천의 문」으로 **이십 년 전**(신체 15세·화산 입문 직전)으로 회귀한다.
- **나이 공식**: 15세 입문 → 이십 년 뒤 35세 사망. 시스템 「이십 년 전」과 일치.

## 주요 세력

| 세력 | 역할 | 비고 |
|------|------|------|
| 화산 / 자하문 | 정파 검문. 정통·방계·이대·원로 구조 | 주인공 소속 |
| 마교 | 본산 + 방외 지파로 분열 | 본산은 숙청 세력 |
| 무림맹 | 표면상 정파 연합 | 전생 배후의 「백발 노인」과 연결 |
| 남궁세가 | 방계 출신 남궁린. 일부 파벌이 노인 추적 | 삼 대째 추적 |
| 성가장 | 명문 무가. 성유 출신 | |
| 혈랑채 | 흑도. 왕삼도 | 하산 시험 표적(6장, 사망) |
| 안개 낀 사원 | 「판의 주인」 거점 | 검은 옥 **판(板)** |

## 핵심 음모

1. 정파와 마교는 **한 뿌리의 두 가지**(검성 유지).
2. 백발 노인(「판의 주인」)이 판 위 이름으로 도구·첩자를 백 년 단위로 조종한다.
3. 한백강 임무명 **「매화 아래에 심어 두는 씨앗(梅下埋種)」** — 이십 년 뒤 검신을 벨 검으로 키움.
4. 12장 이후: 첫 판이 흔들렸고, **두 번째 판**과 매화 아래 아홉 중 **스파이 둘**이 열린다.

## 지리·무대

- 섬서 화산 일대(남봉·검총·흙집)
- 산동(한백강 위장 출신 설정)
- 감숙·청해·사천 등 강호 무대

## 금지·주의 (세계관)

- 사망한 인물을 설명 없이 살려 쓰지 않는다. (`characters.md` 상태 확인)
- 「판」을 모르는 인물이 판의 내부 용어를 함부로 쓰지 않는다.
- 세력 소속·정통/방계 서열을 장마다 임의로 바꾸지 않는다.
