# 검신귀환록 — 등장인물

> 이미지 프롬프트는 `art/character_sheet_prompt.md`에 보관. **본문 나이·설정은 이 파일을 우선**한다.

## 상태 범례

- **생존 / 사망 / 전생만 / 미등장**
- 나이: 현생 기준. 전생은 별도 표기.

---

## 진무한(陳武寒) — 주인공

| 항목 | 내용 |
|------|------|
| 나이 | 전생 사망 **35세**. 회귀 후 입문 **15** → 하산 **18** → 이대 승격 **19**(12장) |
| 소속 | 화산 정통 → 이대 서열 23번째. 전생 말년: 문파 밖 천하제일검 |
| 성격 | 계산·가면. 어머니·동료를 지키려는 온기와 살의가 공존. 말수 적고 눈빛이 깊음 |
| 상태 | 전생 사망 → 현생 **생존** |
| 핵심 | 한매심법·낙매십삼검/검신무. 검총에서 소검·일검단천. 무혼 개화(7장). 「판의 자」 |

## 한백강(韓白剛) — 이중자

| 항목 | 내용 |
|------|------|
| 나이 | 전생: 사형 살해 후 같은 밤 독사. 회귀 후 마교에서 **12세** → 입문 **15** → 현생 동기 **18~19** |
| 소속 | 표면 화산 **방계**. 실체: 마교에 심어진 검 → 진무한의 첫 **이중자** |
| 성격 | 사람 좋은 미소 아래 냉정. 회귀 후 죄책과 전향 |
| 상태 | 전생 사망 → 현생 **생존** |
| 핵심 | 애검 **백야**. 천마의 눈 파편. 산동 고아 대사는 주입된 스크립트 |

## 서령란(徐嶺蘭)

| 항목 | 내용 |
|------|------|
| 나이 | 현생 첫 만남 **16**(10장) → 봄 재회 **17**(12장). 전생: 진무한 25세 때 그녀 24세 → **30세** 본산 숙청으로 사망 |
| 소속 | 마교 **방외 지파** 소성녀(본산 소성녀 아님) |
| 성격 | 냉철하되 사람다운 마교의 얼굴 |
| 상태 | 현생 **생존** |
| 핵심 | 매화 잎 세 장 암호. 지파도 삼 대째 노인 추적 |

## 청허진인(淸虛眞人)

| 항목 | 내용 |
|------|------|
| 나이 | 노년(구체 수치 미확정). 외형 참고: 60대 후반 가능 |
| 소속 | 화산 최고위 원로 |
| 성격 | 말수 적고 깊이 재는 눈 |
| 상태 | **생존** |
| 핵심 | 백 년 전 검성 유지를 기다림. 진무한을 뿌리 벨 검으로 공인(11장) |

## 성유(成瑜)

| 항목 | 내용 |
|------|------|
| 나이 | 동기 코호트 **약 18~19** |
| 소속 | 성가장 셋째, 화산 **정통** |
| 성격 | 밝고 자신만만. 명문 자제 |
| 상태 | **생존** |
| 핵심 | 하산 조장·공식 보고. 음모 핵심 밖. 서령란 이름·약속을 모름 |

## 남궁린(南宮璘)

| 항목 | 내용 |
|------|------|
| 나이 | 동기 **약 18~19** |
| 소속 | 남궁세가 **방계** → 파벌 검객과 연계 |
| 성격 | 과묵·관찰력. 말 거의 없음 |
| 상태 | **생존** |
| 핵심 | 노인 추적 세력의 접점. 발자국·필체로 처단을 간파 |

## 왕삼도(王三刀)

| 항목 | 내용 |
|------|------|
| 나이 | 중장년(약 40대) |
| 소속 | 혈랑채 두목 |
| 상태 | **사망**(6장, 진무한 매화귀토) |
| 핵심 | 천마의 눈 조각 소지. 판/그림자 명부 삼류 하위 |

## 백발 노인 — 「판의 주인」

| 항목 | 내용 |
|------|------|
| 나이 | 백 년 이상 스케일 |
| 소속 | 정파·마교를 관통하는 숨은 손 |
| 상태 | **생존**(12장에서 살려둠) |
| 핵심 | 잿빛 눈·백발. 첫 판 상실 후 **두 번째 판** 가동. 본명 **미회수** |

## 어머니 (이름 미상)

| 항목 | 내용 |
|------|------|
| 관계 | 진무한의 어머니. 남편은 진무한 3세 때 사망 |
| 전생 | 진무한 17세 무렵 홀로 **아사** |
| 상태 | 현생 **생존**. 12장 봉록으로 밭일·삯바느질에서 해방 선언 |
| 역할 | 회귀의 감정적 닻. 「삼 년 뒤 모셔오겠다」 약속 |

## 소하(素霞)

| 항목 | 내용 |
|------|------|
| 관계 | 전생 사랑하던 여인 |
| 상태 | 전생 사망·현생 **미등장** |
| 비고 | 1장 한 줄 복선만 존재 |

## 성격·말투 고정 (붕괴 방지)

| 인물 | 말투·행동 규칙 |
|------|----------------|
| 진무한 | 짧게. 속마음은 독백. 소년 몸에 늙은 눈 |
| 한백강 | 표면은 부드럽고 공손. 진심이 드러날 때만 금이 감 |
