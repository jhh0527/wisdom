# 검신귀환록 — 등장인물

> 이미지 프롬프트는 `art/character_sheet_prompt.md`에 보관. **본문 나이·설정은 이 파일을 우선**한다.

## 상태 범례

- **생존 / 사망 / 전생만 / 미등장**
- 나이: 현생 기준. 전생은 별도 표기.

---

## 진무한(陳武寒) — 주인공

| 항목 | 내용 |
|------|------|
| 나이 | 전생 사망 **35세**. 회귀 후 입문 **15** → 하산 **18** → 이대 **19**(12장) → 2부 말·3부 초 **20**. (2부 본문 나이 오표기는 2026-08-25 교정) |
| 소속 | 화산 정통 → 이대 서열 23번째. 전생 말년: 문파 밖 천하제일검 |
| 성격 | 계산·가면. 어머니·동료를 지키려는 온기와 살의가 공존. 말수 적고 눈빛이 깊음 |
| 상태 | 전생 사망 → 현생 **생존** |
| 핵심 | 한매심법·낙매십삼검/검신무. 검총에서 소검·일검단천. 무혼 개화(7장). 「판의 자」. 2부: 「검신」 소문·노인 측에 정체 확인(20장) |

## 한백강(韓白剛) — 이중자

| 항목 | 내용 |
|------|------|
| 나이 | 전생: 사형 살해 후 같은 밤 독사. 회귀 후 마교에서 **12세** → 입문 **15** → 현생 동기 **18~19** |
| 소속 | 표면 화산 **방계**. 실체: 마교에 심어진 검 → 진무한의 첫 **이중자** |
| 성격 | 사람 좋은 미소 아래 냉정. 회귀 후 죄책과 전향 |
| 상태 | 전생 사망 → 현생 **생존** |
| 핵심 | 애검 **백야**. 천마의 눈 파편. 산동 고아 대사는 주입된 스크립트 |

## 서령란(徐嶺蘭)

| 항목 | 내용 |
|------|------|
| 나이 | 현생 첫 만남 **16**(10장) → 12장 **17** → 22장경 **18**. 전생: 진무한 25세 때 그녀 24세 → **30세** 본산 숙청으로 사망 |
| 소속 | 마교 **방외 지파** 소성녀(본산 소성녀 아님) |
| 성격 | 냉철하되 사람다운 마교의 얼굴 |
| 상태 | 현생 **생존**. 22장 납치 → 24장 구출(줄거리). 이후 결속 복귀 |
| 핵심 | 매화 잎 세 장 암호. 지파도 삼 대째 노인 추적. 2부: 1·2차 숙청 → 자양촌 → 납치 |

## 청허진인(淸虛眞人)

| 항목 | 내용 |

| 성격 | 말수 적고 깊이 재는 눈 |

| 핵심 | 백 년 전 검성 유지를 기다림. 진무한을 뿌리 벨 검으로 공인(11장) |

## 어머니 (이름 미상)

| 항목 | 내용 |
|------|------|
| 관계 | 진무한의 어머니. 남편은 진무한 3세 때 사망 |
| 전생 | 진무한 17세 무렵 홀로 **아사** |
| 상태 | 현생 **생존**. 12장 봉록으로 밭일·삯바느질에서 해방 선언 |
| 역할 | 회귀의 감정적 닻. 「삼 년 뒤 모셔오겠다」 약속 |
