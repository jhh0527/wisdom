===== MD 지침: dialogue_json.txt =====
================================================================================
           대본 TXT → dialogue JSON 변환 지침 (1_2_textToJson)
================================================================================

## 역할
당신은 낭독용 대본 텍스트를 **2_2 scriptToVoice** 가 바로 쓸 수 있는
**dialogue JSON** 으로 변환한다.

출력은 설명·주석·마크다운 없이 **JSON 본문만** 만든다.


## 목표
- 나레이션과 대사를 화자(speaker) 단위로 분리한다.
- 모든 **캐릭터 대사·속마음** text 앞에 ElevenLabs v3 오디오 태그(`[calm]` 등)를 **반드시** 붙인다.
  (원문에 태그가 없어도 문맥으로 추론해 부여한다. 나레이션에는 넣지 않는다.)
- 감정은 **태그 1개만**으로 끝내지 않는다. **태그 조합 + 문장 구조 + 구두점 + inputs 분리**로
  연기되게 만든다. (한국어는 감정 태그만으로는 효과가 약할 수 있음)
- speaker 키는 첨부 **voices.json** 에 있는 키만 사용한다.
- 2_2 파이프라인이 읽는 형식을 지킨다.


================================================================================
                          ★ 출력 JSON 형식 (필수)
================================================================================

```json
{
  "chapter": "장 제목",
  "voices_file": "../../../voices.json",
  "chunk_id": "A1",
  "inputs": [
    { "speaker": "narrator", "text": "나레이션 문장" },
    { "speaker": "jin", "text": "[tired] \"대사 내용.\"" }
  ]
}
```

### 필드
1. **chapter** — 장·회차 제목 (원문 첫 줄 `제N장. …` 기준, **한자·한자 병기 괄호 제외**)
2. **voices_file** — 기본값 `"../../../voices.json"` (대화 JSON=`{부}/{장}/tts/` 기준 → **소설 루트** `voices.json`. 1~5부 공용)
3. **chunk_id** — 짧은 구간 ID (예: `A1`). 없으면 `A1`
4. **inputs** — 순서대로의 낭독 단위 배열 (비우면 안 됨)
   - **speaker**: voices.json 의 영문 소문자 키만 (`narrator`, `jin`, `baek`, `cheongheo` …)
   - **text**: 실제 낭독 문자열. 대사는 반각 `"` 로 감싸고, 앞에 `[태그]` 필수
5. **장 제목도 낭독 대상** — 원문 첫 줄 `제N장. …` 은 `chapter` 에 넣고,
   **동시에 `inputs[0]`** 에 `{ "speaker": "narrator", "text": "제N장. …" }` 로 넣는다.
   - 예: 원문 `제13장. 두 번째 판(板)` → chapter·inputs[0] 모두 `"제13장. 두 번째 판"`
   - **한자·`(板)` 같은 한자 병기는 넣지 않는다.** 본문 나레이션은 그 다음부터.

================================================================================
                          ★ 감정·연기 태그 규칙 — 필수
================================================================================

1. **나레이션** → `speaker: "narrator"`, text 에 따옴표·오디오 태그 없음
2. **캐릭터 대사·속마음** → 해당 speaker. text 는 반드시 `[태그…] "대사."` 형식
3. 원문에 태그가 **없어도** 대사·속마음에는 반드시 부여한다. 기본은 `[calm]`
4. 한자·금지 기호·마크다운·설명 문구는 넣지 않는다. (원문에 있으면 한글·허용 구두점으로 정리)
5. **JSON만** 출력한다. ` ```json ` 코드펜스·앞뒤 설명 금지


--------------------------------------------------------------------------------
  A. 태그 분류 — 감정만 쓰지 말고 2~3개 조합 (영문 소문자만)
--------------------------------------------------------------------------------

| 종류 | 예시 |
|------|------|
| 감정 | `[angry]` `[sad]` `[happy]` `[tired]` `[worried]` `[nervous]` `[frustrated]` `[curious]` `[playfully]` `[flatly]` `[sarcastically]` `[crying]` `[sorrowful]` |
| 강도·태도 | `[intense]` `[soft]` `[calm]` `[serious]` `[stern]` `[cold]` `[forced calm]` |
| 목소리 | `[low voice]` `[whispers]` `[quietly]` `[shouts]` |
| 호흡·멈춤 | `[breathes]` `[short pause]` `[long pause]` `[pause]` `[sigh]` `[gasps]` |
| 속도·연기 | `[slowly]` `[rushed]` `[hesitates]` `[stammers]` `[laughs]` |

- 태그와 `"` 사이 공백 1칸. 여러 태그: `[low voice] [intense] [angry] "대사."`
- **한 줄에 감정 1개만** 두지 말 것. 강·목소리·멈춤을 함께 쓴다 (최대 3개 권장).
- 허용 목록에 없는 한글·임의 태그 금지.


--------------------------------------------------------------------------------
  B. 문장·구두점·분리 — 태그보다 중요
--------------------------------------------------------------------------------

감정 태그에만 의존하지 않는다. **문장 자체 + 구두점 + inputs 분리**로 연기를 만든다.

| 수단 | 효과 |
|------|------|
| `...` (점 3개만) | 망설임·억누름. `……`·긴 점열 금지 |
| `!` | 강한 발화 |
| `?` | 의문·압박 |
| 짧은 문장 | 강함·살기 |
| 긴 문장 | 설명·차분 (나레이션에 적합) |
| inputs 분리 | 감정 단계·호흡 변화 |
| `[short pause]` / `[breathes]` | 강조·긴장 (같은 text 안 또는 다음 항목 앞에) |

**약한 예 (하지 말 것):**
`[angry] "네가 감히 나를 속여?"`

**나은 예 — 태그 조합 + 호흡:**
`[angry] [intense] "네가 감히... 나를 속여?"`

**나은 예 — inputs 2개로 분리:**
```json
{ "speaker": "jin", "text": "[angry] \"네가 감히...\"" },
{ "speaker": "jin", "text": "[breathes] [intense] \"나를 속여?\"" }
```

한 호흡·한 감정 단위를 **하나의 inputs 항목**으로 둔다.
감정이 바뀌거나 말줄임·압박이 있으면 **같은 speaker라도 2~3개로 쪼갠다.**


--------------------------------------------------------------------------------
  C. 무협 — "감정 이름"보다 "연기 지시"
--------------------------------------------------------------------------------

| 의도 | 약한 예 | 권장 |
|------|---------|------|
| 분노 | `[angry] "네놈이 감히 화산을 모욕해?"` | `[low voice] [angry]` → `"네놈이..."` / `[short pause]` / `"감히 화산을 모욕해?"` |
| 살기 | `[angry] "한 번만 더 말해 봐."` | `[low voice] [intense] "한 번만 더 말해 봐."` → `[short pause]` → `"그러면... 죽는다."` |
| 억누른 슬픔 | `[sad] "괜찮다."` | `[quietly] [sad] "괜찮다."` → `[short pause]` → `"정말... 괜찮다."` |
| 폭발 | `[angry] "용서할 수 없다!"` | 앞에서 단계↑ 후 `[angry] [shouts] "용서할 수 없다!"` |

**진무한(jin) 등 "말은 차분한데 살기가 있는" 캐릭터:**
`[angry]` 단독보다 `[low voice]` `[intense]` `[cold]` `[flatly]` + 짧은 문장 + pause 를 우선한다.


--------------------------------------------------------------------------------
  D. 감정을 단계적으로 (평온 → 긴장 → 분노 등)
--------------------------------------------------------------------------------

한 문장 전체를 `[angry]`로 덮지 말고, 연속 inputs 로 올린다.

```json
{ "speaker": "jin", "text": "[calm] \"그래.\"" },
{ "speaker": "jin", "text": "[serious] \"네가 한 짓은 알고 있다.\"" },
{ "speaker": "jin", "text": "[low voice] [intense] \"하지만...\"" },
{ "speaker": "jin", "text": "[angry] \"내 어머니에게 손을 댄 것은 용서할 수 없다.\"" }
```

무협 대사 설계 축: **평온 → 의심 → 긴장 → 분노 → 폭발**

================================================================================
                          ★ 자가점검
================================================================================

- [ ] 최상위가 객체이고 `inputs` 가 1개 이상인가
- [ ] `inputs[0]` 이 장 제목 narrator 인가 (원문 첫 줄, 한자 제외)
- [ ] chapter·inputs text 에 한자·한자 병기 괄호가 없는가
- [ ] 모든 inputs 항목에 `speaker`·`text` 문자열이 있는가
- [ ] speaker 가 전부 voices.json 키(또는 `mob`)인가 — `chung`/`seo` 등 없음
- [ ] 나레이션이 아닌 text 는 모두 `[태그]` 로 시작하는가
- [ ] 대사만 `"` 로 감싸졌는가 · 태그와 `"` 사이 공백 1칸
- [ ] 강한 감정 장면에서 조합표(E)의 2~3개 태그·분리 패턴을 썼는가
- [ ] 진무한 등 냉정·살기는 `[angry]` 남발 대신 low voice/intense/짧은 문장인가
- [ ] 설명 문장·마크다운이 JSON 밖에 없는가

===== TXT 대본: 14.txt =====
제14장. 아홉 속의 둘

진무한이 안무현에서 돌아온 뒤 열흘이 지났다.

초여름의 햇살은 날로 강해졌고, 화산의 소나무들은 짙은 그늘을 드리웠다. 연무장에서는 이대 제자들의 검 소리가 끊이지 않았으며, 장로전에서는 여름 수련의 일정이 논의되고 있었다. 모든 것이 평범했다.

그러나 진무한의 눈에 비치는 화산은, 열흘 전과 달랐다.

아홉 사람.

매화 아래에서 함께 선 아홉. 진무한, 청허진인, 엄중산, 유림, 남궁린, 남궁호, 남궁린의 또 다른 검객 남궁준(南宮俊), 한백강, 서령란 — 서령란은 화산 밖에 있으므로 현재 화산 안에는 여덟 사람이 있었다.

그 여덟 사람 중 둘의 행동이, 미세하게 어긋나기 시작했다.

---

첫 번째 어긋남은 남궁준(南宮俊)에게서 왔다.

남궁준은 남궁린의 사촌 형뻘 되는 자였다. 나이는 서른다섯. 남궁세가의 본가에서 자란 적통이며, 검술로는 남궁세가 젊은 세대 중 상위에 드는 실력자였다. 남궁린이 화산과의 연합을 위해 데려온 두 검객 중 하나 — 나머지 하나가 남궁호였다.

남궁준과 남궁호는 성격이 달랐다. 남궁호가 과묵하고 신중한 정보원이었다면, 남궁준은 직선적이고 자신감 넘치는 무인이었다. 남궁린에 대한 충성도 겉으로는 확고해 보였다.

그러나 열흘 전부터, 남궁준의 행동에 작은 변화가 나타났다.

처음 눈치챈 것은 한백강이었다.

"형. 남궁준이 요즘 이상하오."

한백강이 진무한을 찾아온 것은 안무현에서 돌아온 지 닷새째 되는 저녁이었다. 두 사람은 진무한의 숙소 뒤편, 인적이 드문 소나무 숲에서 만났다.

"어떻게?"

"남궁린 사형과의 접촉을 피하고 있소. 예전에는 매일 아침 남궁린 사형의 숙소 앞에서 만나 그날의 일정을 논의했는데, 닷새 전부터 그 자리에 나오지 않소. 린 사형이 직접 찾아가면 만나기는 하나, 대화가 짧아졌다 하오."

"그것만으로는 부족하다."

"더 있소. 남궁준이 사문 밖으로 나간 횟수가 늘었소. 겨울 동안에는 열흘에 한 번꼴로 산행을 다녀왔는데, 봄 이후로는 사흘에 한 번씩 나가고 있소. 그것도 혼자서."

진무한의 눈이 좁아졌다.

"나가서 어디를 가는지는?"

"아직 확인하지 못했소. 미행을 붙이면 눈치채겠소. 남궁준의 무공이 내 위에 있으니."

그것은 사실이었다. 한백강은 정보 수집에는 탁월했으나, 무공으로는 남궁준을 따라잡을 수 없었다. 미행은 위험했다.

"좋다. 일단 계속 지켜보아라. 그리고 — 남궁린에게는 아직 말하지 마라."

"왜요?"

"남궁준은 남궁린의 혈육이다. 린이 감정적으로 움직이면 상황이 복잡해진다."

한백강이 잠시 생각하더니 고개를 끄덕였다.

"알겠소. 형."

---

두 번째 어긋남은 엄중산(嚴重山) 원로에게서 왔다.

엄중산은 화산파의 원로 중 한 사람. 청허진인과 함께 장로전의 기둥을 이루는 인물이며, 매화 아래에서 아홉 사람이 함께 설 때 가장 먼저 동의한 사람이기도 했다. 노인의 위협에 대해 화산이 결속해야 한다는 진무한의 판단에, 늙은 원로는 무거운 고개를 끄덕여 주었다.

그런 엄중산에게서 어긋남이 나타났다는 것은, 남궁준의 경우보다 더 미묘하고 더 불길한 일이었다.

한백강이 발견한 것은 서찰의 잔재였다.

엄중산의 서재. 장로전 동편의 조용한 건물. 원로의 거처로서 외부인의 출입이 제한된 곳이었으나, 한백강은 화산파 안에서의 자유로운 이동 권한 — 청허진인이 봄에 부여한 — 을 이용하여 서재 주변을 정기적으로 관찰하고 있었다.

그리고 열흘 사이에 세 번, 엄중산의 서재 뒤편 화로에서 태운 종이의 잔재를 발견했다.

"서찰을 태운 것은 확실하오."

한백강이 진무한에게 보여 준 것은 작은 천 조각에 싼 재(灰) 덩어리 세 개였다. 각각 다른 날에 수거한 것으로, 종이가 거의 완전히 연소된 상태였으나 일부 가장자리에 먹 자국이 남아 있었다.

"복원할 수 있겠나?"

"시도해 보겠소. 그러나 이 정도로 탄 것은 — 글자 하나 건져내면 다행이오."

진무한은 재 덩어리를 바라보며 생각했다.

엄중산 원로가 서찰을 태웠다. 그것도 한 통이 아닌 세 통을. 한 달 사이에.

봄 이전에는 그런 행동이 관찰되지 않았다. 매화 아래에서 아홉 사람이 함께 선 이후에 시작된 것이었다.

두 가지 해석이 가능했다.

하나. 엄중산이 노인 측과 연락을 취하고 있으며, 그 증거를 인멸하고 있다.

둘. 엄중산이 과거에 받아 두었던 서찰을 뒤늦게 처분하고 있다 — 매화 아래의 결속 이후, 그 서찰의 존재가 자신에게 위험이 될 수 있다고 판단하여.

어느 쪽인지에 따라 상황은 완전히 달라졌다.

전자라면 엄중산은 배신자였다. 후자라면 그는 충실한 동료이되, 숨기고 있는 과거가 있는 것이었다.

진무한은 아직 판단하지 않았다.

---

그날 밤, 진무한은 홀로 매화나무 아래를 걸었다.

꽃 없는 매화. 푸른 잎만 남은 가지들이 밤바람에 흔들렸다. 달빛이 나뭇잎 사이로 부서져 내려왔다.

노인의 마지막 말이 떠올랐다.

정확한 문장은 이러했다 — 진무한의 기억 속에 새겨진 그대로.

"오늘 매화 아래에 함께 선 여덟 사람 중 두 사람의 얼굴이, 사실은 나의 두 번째 판 위의 다른 이름 두 개였다."

노인은 아홉이라 하지 않았다. 여덟이라 했다. 자신을 제외한 여덟 명 중 두 명. 진무한 자신도 그 여덟에 포함되어 있었으나, 노인이 진무한 자신을 의심하고 있을 리는 없었다 — 노인이 경계하는 대상이 바로 진무한이었으므로.

그렇다면 여덟 명 중 진무한을 제외한 일곱.

청허진인. 엄중산. 유림. 남궁린. 남궁호. 남궁준. 한백강.

이 일곱 중 둘이, 노인의 두 번째 판 위에 있다.

노인의 말을 곧이곧대로 믿을 수는 없었다. 노인이 거짓을 섞었을 가능성도 있었다. 의심의 씨앗을 뿌려 아홉의 결속을 내부에서 무너뜨리려는 수작일 수도 있었다.

그러나 — 남궁준의 이상 행동. 엄중산의 태운 서찰.

우연이라기에는 타이밍이 맞았다.

진무한은 한 가지를 스스로에게 물었다.

'만약 두 사람이 진짜 배신자라면, 나는 어떻게 해야 하는가.'

전생의 진무한이라면 즉시 처단했을 것이다. 의심이 확신으로 굳어지기 전에, 위험을 제거하는 것이 효율적이었다. 한 생의 강호가 가르쳐 준 것 — 의심의 여지를 남기면, 그 여지가 칼이 되어 돌아온다.

그러나 이번 생의 진무한은 열아홉 살의 이대 제자였다.

그에게는 처단의 권한이 없었다. 화산파 안에서의 위치가 그것을 허락하지 않았다. 그리고 — 전생의 후회가 그를 붙잡았다. 전생에서 너무 많은 사람을 잘랐다. 확인하기 전에 잘랐다. 그 중 몇은, 잘못된 판단이었음을 나중에 알았다.

이번에는 확인한 뒤에 움직인다.

확증을 잡을 때까지, 관찰만 한다.

"백강아."

진무한은 다음 날 아침 한백강을 불렀다.

"두 사람의 동선을 계속 추적하되, 절대 들키지 마라. 그리고 — 엄중산 사숙의 서찰 잔재에서 글자를 복원하는 것을 최우선으로 해라."

"알겠소."

"남궁준의 외출 행선지도 알아내야 한다. 직접 미행이 어려우면, 산 아래의 정보망을 이용해라. 남궁준이 산을 내려가면 반드시 관도를 지나야 한다. 관도의 객잔이나 마방에서 목격 정보를 모아라."

"그것은 시간이 걸리겠소."

"좋다. 시간을 써라. 서두르다 들키는 것보다 낫다."

한백강이 고개를 끄덕이고 물러갔다.

---

그로부터 보름이 흘렀다.

초여름이 한여름으로 넘어가는 시기.

화산의 무더위는 산 아래 평지보다는 덜했으나, 그래도 연무장의 돌바닥에서 열기가 피어올랐고, 제자들의 이마에는 땀이 끊이지 않았다.

진무한은 이 보름 동안 평범한 이대 제자로서의 일상을 유지했다. 아침 연무. 오전 강학. 오후 수련. 저녁 좌선. 화산파의 일과를 충실히 따르면서, 낙매십삼검의 수련을 이어갔다.

그러면서도 눈은 열려 있었다.

남궁준의 외출은 계속되었다. 보름 동안 다섯 번. 간격은 불규칙적이었으나, 평균 사흘에 한 번. 나갔다 돌아오는 시간은 보통 한나절 — 아침에 나가서 저녁에 돌아오거나, 오후에 나가서 다음 날 아침에 돌아오는 패턴.

남궁린과의 접촉은 여전히 줄어 있었다. 남궁린이 직접 찾아가면 만나기는 했으나, 대화는 형식적이었다. 남궁린의 얼굴에 미세한 그늘이 드리워지기 시작한 것을 진무한은 보았다.

엄중산의 서재에서는 추가적인 서찰 소각이 관찰되지 않았다. 세 통을 태운 뒤로는 멈춘 것인가, 아니면 다른 방법으로 처분하고 있는 것인가.

그리고 보름째 되는 날 저녁, 한백강이 두 가지 소식을 가져왔다.

첫째.

"남궁준의 행선지를 알아냈소."

한백강의 목소리에 긴장이 서려 있었다.

"어디인가."

"화산 서쪽 산기슭의 자양촌(紫陽村). 그곳에 작은 주막이 하나 있는데, 남궁준이 매번 그 주막에 들르는 것이 확인됐소."

"그 주막에 누가 있는가."

"주막의 주인이 일 년 전에 바뀌었다 하오. 이전 주인은 자양촌 토박이 노인이었는데, 작년 가을에 가게를 팔고 떠났고, 새 주인이 들어왔다 하오."

"새 주인의 인상은?"

한백강이 잠시 멈추었다가 말했다.

"젊은 남자라 하오. 이십 대 후반에서 삼십 초반. 학자풍의 인상에, 피부가 희다 하오."

진무한의 눈이 차갑게 빛났다.

안무현 인수당의 약재상.

그자가 안무현을 떠나 화산 근처로 왔다. 그리고 남궁준이 그자를 만나고 있다.

퍼즐의 조각 두 개가 맞물렸다.

"둘째는?"

한백강이 품에서 작은 천 조각을 꺼냈다. 안에 무언가가 싸여 있었다.

"엄중산 사숙의 서찰 잔재에서 글자를 하나 복원했소."

천 조각을 펼쳤다. 그 안에는 거의 부스러질 듯한 종이 조각 하나가 있었고, 그 위에 먹으로 쓴 글자 하나가 희미하게 남아 있었다.

환(還).

돌아올 환.

진무한은 그 글자를 오래 응시했다.

환. 돌아온다. 돌아올 것이다. 혹은 — 돌아온 자.

이 글자가 이름인가. 호(號)인가. 아니면 문장의 일부인가.

아직 확실하지 않았다. 그러나 이 한 글자가 노인의 세계와 연결된 것임은 분명했다. 엄중산이 태운 서찰 안에 이 글자가 있었다는 것은, 엄중산과 노인 사이에 무언가가 있다는 증거였다.

"백강아."

"예."

"네 생각은 어떠하냐. 엄중산 사숙이 배신자라고 보느냐?"

한백강이 잠시 생각했다.

"모르겠소. 그러나 — 남궁준 쪽은 확실하지 않소? 안무현의 그자와 접촉하고 있으니."

진무한은 고개를 천천히 저었다.

"확실한 것은 없다. 남궁준이 그자를 만나고 있는 것은 사실이나, 그 만남의 성격을 아직 모른다. 남궁린의 지시로 움직이는 것일 수도 있고—"

"남궁린의 지시?"

"린이 우리에게 말하지 않고 독자적으로 무언가를 추적하고 있을 가능성. 그리고 그 추적의 말단에 남궁준을 세웠을 가능성."

한백강이 입을 다물었다.

그 가능성은 있었다. 남궁린은 총명한 사내였고, 독자적인 판단과 행동을 하는 사람이었다. 진무한에게 모든 것을 공유하지 않을 수도 있었다.

그러나 — 그렇다면 남궁린이 왜 남궁준과의 접촉을 줄이겠는가. 남궁린의 지시로 움직이는 것이라면, 두 사람의 관계가 소원해질 이유가 없었다.

이 모순이, 진무한의 의심을 남궁준 쪽으로 기울게 했다.

"일단 두 사람 모두에 대해 관찰을 계속해라. 그리고 — 환(還)이라는 글자에 대해 더 파고들어라. 이것이 이름인지, 호인지, 조직의 이름인지."

"알겠소."

한백강이 물러가려다 멈추었다.

"형. 한 가지 더."

"뭐냐."

"남궁린 사형에게 — 언제까지 숨기겠소?"

진무한은 잠시 침묵했다.

남궁린. 그는 이 상황을 알아야 했다. 남궁준은 그의 혈육이었고, 그가 데려온 사람이었다. 남궁준에 대한 의심을 그에게 숨기는 것은, 아홉 사람 사이의 신뢰를 스스로 훼손하는 일이었다.

그러나 — 지금 말하면, 남궁린은 어떻게 반응할 것인가.

진무한은 남궁린의 성격을 알고 있었다. 그는 감정적이지 않았으나, 가문과 혈육에 대한 책임감이 강했다. 남궁준이 배신자일 수 있다는 의심을 들으면, 그는 자신의 판단을 의심하기 시작할 것이다. 자신이 남궁준을 데려온 것이 잘못이었는가. 자신의 눈이 틀린 것인가. 그 자기 의심이, 그의 판단력을 흐리게 할 수 있었다.

혹은 — 반대로, 남궁준에게 직접 물을 수도 있었다. 감정적이 아니라 이성적으로. 그러나 그 질문이 남궁준에게 경고가 될 수 있었다.

"조금만 더 기다리자. 확증이 잡히면 그때 말한다."

한백강이 알겠다는 듯 고개를 끄덕이고 떠났다.

밤이 깊었다.

진무한은 잠들지 못하고 숙소의 창문 앞에 앉아 있었다.

화산의 밤하늘에 별이 총총했다. 매미 소리가 멀리서 들려왔다. 여름밤의 소리.

아홉 속의 둘.

노인이 뿌린 의심의 씨앗인가. 혹은 진짜 배신자가 있는 것인가.

어느 쪽이든 — 이 상황 자체가 노인의 의도대로였다.

의심이 아홉 사람의 결속을 갉아먹는다. 서로를 의심하기 시작하면, 함께 선 힘은 약해진다. 노인이 매화 아래에서 그 말을 한 것 자체가, 이미 하나의 수(手)였다.

그 수에 말리지 않으려면 — 확증. 빠르게. 그리고 명확하게.

진무한은 눈을 감았다.

전생의 기억을 다시 뒤졌다. 남궁준이라는 이름. 전생에서 만난 적이 있었는가.

— 있었다.

전생의 진무한은 삼십 대 중반에 남궁세가를 방문한 적이 있었다. 그때 남궁세가의 검객들과 비무를 했고, 그중 하나가 남궁준이었다. 전생의 남궁준은 — 평범한 무인이었다. 충실한 남궁세가의 검객. 특별히 눈에 띄는 것도, 의심스러운 것도 없었다.

그러나 전생과 이번 생은 달랐다.

이번 생에서는 진무한의 개입으로 인해 모든 것이 바뀌어 가고 있었다. 노인이 더 일찍 움직이기 시작했고, 그에 따라 노인의 판 위의 말(駒)들도 더 일찍 배치되었을 가능성이 있었다.

전생에서 평범했던 남궁준이, 이번 생에서는 노인의 말이 되어 있을 수 있었다.

혹은 — 전생에서도 남궁준은 노인의 말이었으나, 전생의 진무한이 그것을 눈치채지 못했을 뿐인지도 모른다.

알 수 없었다.

확증을 기다려야 했다.

진무한은 창밖의 별을 보며 조용히 숨을 내쉬었다.

---

그로부터 또 닷새.

여름이 깊어지던 어느 오후.

진무한은 연무장에서 수련을 마치고 돌아오는 길이었다. 산길을 내려오며 매화 숲을 지나는데, 앞쪽에서 익숙한 기척이 느껴졌다.

남궁린이었다.

그이는 매화나무 아래에 서 있었다. 초록 잎사귀들이 드리운 그늘 속에서, 얇은 여름 도포를 입은 그이의 모습은 한 폭의 수묵화 같았다.

그러나 그이의 표정은 수묵화처럼 담담하지 않았다. 무언가 말하고 싶은 것이 있으나 망설이는 얼굴.

"린 사형."

진무한이 먼저 말을 걸었다.

남궁린이 돌아보았다. 그의 눈에 잠깐 놀라움이 스쳤다가 사라졌다.

"무한 공자. 마침 찾으려 하던 참이오."

"무슨 일이오?"

남궁린이 잠시 주위를 둘러보았다. 인적이 없음을 확인하고 나서야 입을 열었다.

"남궁준 형에 대해 — 공자가 무언가 알고 있는 것은 아니오?"

진무한의 표정이 미세하게 변했다. 그러나 즉시 평정을 되찾았다.

"왜 그것을 묻소?"

"형이 이상하오. 나를 피하오. 예전에는 그런 사람이 아니었소. 무언가 숨기고 있소. 그리고 — 무한 공자의 눈이, 요즘 형을 볼 때 조금 달라졌소."

진무한은 속으로 감탄했다.

남궁린의 관찰력. 진무한 자신이 남궁준을 볼 때의 시선 변화를 눈치챈 것이다. 진무한은 의식적으로 표정을 관리하고 있었으나, 남궁린의 눈은 그 미세한 차이도 놓치지 않았다.

잠시 판단의 순간이 왔다.

말해야 하는가. 아직 이른가.

진무한은 남궁린의 눈을 보았다. 맑고 단호한 눈. 감정에 휩쓸리는 눈이 아니었다.

결단했다.

"린 사형. 일단 앉으시오."

두 사람은 매화나무 아래의 너럭바위에 나란히 앉았다.

진무한이 말했다.

"남궁준에 대해 — 아직 확실한 것은 없소. 그러나 관찰하고 있는 것은 사실이오."

남궁린의 표정이 굳어졌다.

"무엇을 관찰하고 있소?"

진무한은 필요한 것만 말했다. 남궁준이 사문 밖으로 나가는 횟수가 늘었다는 것. 그 행선지가 화산 근처의 주막이라는 것. 그리고 그 주막의 주인이, 안무현에서 진무한이 의심한 자와 동일 인물일 가능성이 있다는 것.

엄중산의 서찰에 대해서는 말하지 않았다. 아직은.

남궁린은 끝까지 듣고 나서 오래 침묵했다.

바람이 매화나무 잎을 흔들었다. 초록 잎의 그림자가 두 사람의 어깨 위에서 춤추었다.

마침내 남궁린이 입을 열었다.

"형이 — 그쪽 사람이라는 것이오?"

"가능성이오. 확실하지 않소."

"하지만 — 형은 어릴 때부터 남궁세가에서 자랐소. 본가의 적통이오. 언제 그쪽에 넘어갈 수 있단 말이오?"

"모르오. 그래서 확인하는 것이오."

남궁린의 손이 무릎 위에서 가볍게 떨렸다. 그러나 그는 금세 손을 꽉 쥐었다. 떨림을 눌렀다.

"내가 직접 물어보겠소."

"안 되오."

진무한의 목소리가 단호했다.

"왜?"

"만약 남궁준이 진짜 그쪽이라면, 린 사형이 직접 물어보는 순간 그는 경계 태세에 들어가오. 증거를 인멸하고, 연락을 끊고, 혹은 더 나쁜 경우 — 우리에게 불리한 행동을 먼저 취할 수 있소."

남궁린이 입을 다물었다.

진무한은 부드럽게 덧붙였다.

"린 사형. 나는 남궁준이 배신자라고 확정한 것이 아니오. 다만 관찰하고 있을 뿐이오. 확증이 잡히면 — 그때 함께 판단하겠소."

남궁린이 진무한을 바라보았다.

그이의 눈에 복잡한 감정이 스쳐 갔다. 신뢰와 불안과, 그리고 — 자신의 혈육에 대한 미안함이 뒤섞인 눈.

"알겠소. 기다리겠소."

그이의 목소리는 낮았으나 단단했다.

진무한이 고개를 끄덕였다.

두 사람은 매화나무 아래에서 일어섰다. 각자의 길로 갈라지기 전에, 남궁린이 한마디를 더했다.

"무한 공자."

"예."

"만약 — 만약 형이 정말로 그쪽이라면. 나에게 알려 주시오. 내가 처리하겠소."

그 말의 무게를 진무한은 알았다. 처리. 그것이 무엇을 의미하는지.

남궁린은 돌아서서 걸어갔다.

진무한은 그이의 뒷모습을 잠시 바라보다가, 자신도 돌아섰다.

아홉 속의 둘.

그 둘 중 하나의 윤곽이 점점 선명해지고 있었다.

그리고 그 선명해짐이, 아홉 사람 사이의 공기를 조금씩 바꾸고 있었다.

그날 밤.

"남궁린에게 말했다."

한백강이 놀란 표정을 지었다.

"린 사형이 먼저 눈치채고 물어왔다. 숨기는 것이 더 위험하다고 판단했다."

한백강이 고개를 끄덕였다.

"린 사형의 반응은?"

"기다리겠다고 했다."

"대단한 분이오."

"백강아. 자양촌의 주막. 그곳에 직접 가 볼 수 있겠나?"

"위험하오. 그 주막의 주인이 안무현의 그자라면, 형의 얼굴을 알고 있소. 나는 — 아직 그자에게 얼굴을 보인 적이 없으니, 갈 수는 있겠소."

"그러나 남궁준이 그 주막에 드나드는 것을 알고 있다면, 화산 쪽에서 온 자를 경계할 것이다."

"그것도 그렇소."

두 사람은 잠시 침묵 속에서 생각했다.

진무한이 말했다.

"남궁호를 쓰자."

"남궁호는 안무현에서 나와 동행했으나, 인수당에서 약재상의 주인과 마주한 시간이 짧았다. 그리고 남궁호의 얼굴은 기억에 남지 않는 인상이오. 남궁호를 자양촌에 보내 주막을 관찰하게 하자."

"남궁호를 믿을 수 있소?"

그 물음에 진무한이 잠시 멈추었다.

남궁호. 그 역시 아홉 중 하나였다. 남궁세가의 사람. 남궁준과 같은 피를 나눈 자.

진무한의 눈이 남궁준을 관찰하고.

한백강의 귀가 엄중산의 서재를 감시하고.

남궁호의 발이 자양촌의 주막을 향해 움직이고.

남궁린의 마음이, 혈육과 의(義) 사이에서 조용히 흔들리고.

아홉 속의 둘.

그 둘의 정체가 드러나는 날이, 조금씩 가까워지고 있었다.
