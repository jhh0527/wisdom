# 검신귀환록 — 연표

## 전생

| 시점 | 사건 |
|------|------|
| 3세 | 아버지 사망(사냥) |
| ~10세 | 열병. 어머니(당시 약 25세) 간병 |
| 15세 | 화산 입문. 방계 하위(277등). 한백강 업어 줌 |
| 17세 | 어머니 임종 못 지킴·아사 |
| ~20세 | 임소천과 「형」 관계 시작 |
| 23세 | 황도영 사건(소상인 살해) |
| 25세 | 소하 이별/상실. 서령란(24)과 봄 새벽 무승부. 한백강 생일에 백야를 줌 |
| 28세 | 강호의 별. 한백강에게 어머니 이야기 |
| 30세 | 사부 임종 불참·전장. 서령란은 같은 해 본산에 죽음 |
| 32세 | 검총 발견 — 검의만 수득 |
| **35세** | 마교주 처단 → 혈응독·매화귀토로 사망. 한백강도 독사. **회귀** (입문 15세로부터 이십 년) |

## 시간·이동 검수 메모

- 하산·청해·화산 복귀 사이 **계절**이 맞는지 확인.
- 「반 시진」「삼십 분」 단위로 대륙 횡단이 나오면 오류.
- 전생 사망은 **35세**. 「한 생」표현으로 통일. 「사십 년」시적 수사 사용 금지.
