# 검신귀환록 — 관계도

```
                    [백발 노인 / 판]
                   /       |        \
            마교 본산   무림맹·정파    그림자 명부
               |           |         (왕삼도†, 황도영…)
          서령란 지파 ←—— 같은 뿌리 추적 ——→ 남궁 파벌(남궁린)
               \           |           /
                \     한백강(심어진 검→이중자)
                 \         |
                  \    진무한 ←—— 사형제/신뢰 ——→ 한백강
                   \     |  \
                    \    |   +— 조 동료: 성유(표면), 남궁린(동맹)
                     \   |
                      +——+—— 청허·서지원·엄중산 (유지 계승)
                           |
                        어머니 (보호 대상)
                     소하 (전생만)
```

## 핵심 관계

| 관계 | 전생 | 현생 |
|------|------|------|
| 진무한 ↔ 한백강 | 피해자–가해자 | 공범적 동맹·이중자 |
| 진무한 ↔ 서령란 | 호적·추모 | 「검을 맞대지 말자」 약속 |
| 진무한 ↔ 청허 삼인 | 거의 무관 | 후계 검으로 공인 |
| 남궁린 ↔ 서령란 지파 | — | 서로 모른 채 같은 노인 추적 → 진무한 매개 |
| 진무한 ↔ 성유 | — | 표면 동료. 음모 공유 안 함 |
| 진무한 ↔ 어머니 | 방치·상실 | 최우선 보호 |

## 정보 격리 (중요)

|------|-----------|
