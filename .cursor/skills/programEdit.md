

# 공통
프로그램에서 최초 선택한 폴더 상위 폴더가 루트트 폴더가 되게한다.


# 2_1_ttsToVoice (완료)
입력폴더 지정시 mp3폴더 상위 디렉토리가 루트 폴더가 된다.

입력폴더 : 루트 폴더 및에 대소문자 구분하지 않고 mp3 폴더가 디폴트로 지정된다. 
출력폴더 : 디폴트로 입력폴더와 동일하게 지정한다.


# 3_2_pngToJpg 프로그램

변환대상폴더 지정시 png폴더 상위디렉토리가 루트 폴더가 된다.
변환대상폴더: 루트폴더 밑에 png폴더가 디폴트로 지정된다.
저장폴더: 루트풀더 밑에 jpg폴더가 디폴트로 지정된다.



# 3_1_pngFileName
대본srt 폴더 지정시 srt파일이 존재하는 폴더 상위 디렉토리가 루트 폴더가 된다.
대본srt폴더 : 루트폴더 밑에 mp3폴더네 all.srt가 디폴트로 지정된다.

png폴더 : 루트폴더 밑에 png폴더가 디폴트로 지정된다.


# 4-1_video (완료)
오디오mp3 폴더 지정시 mp3파일이 존재하는 폴더 상위 디렉토리가 루트 폴더가 된다.
오디오mp3: 루트폴더 밑에 mp3폴더내 all.mp3 가 디폴트로 지정된다. 
자막srt : 루트폴더 밑에 mp3폴더내 all.srt 가 디폴트로 지정된다.
이미지영상폴더 : 루트폴더 밑에 jpg 폴더가 디폴트로 지정된다.
출력mp4 : 루트폴더가 디폴트로 지정된다.
